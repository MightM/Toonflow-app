# MiniMax H3：对白、说话人与音色

本说明接在「视频模型提示词规则」和「画布视频节点扩写适配说明」之后，只在 H3 系列模型上生效。
蒸馏自官方 T2VA / Ref2VA 指南与社区 JSON Director 规则，完整原文在 `data/skills/h3_skills/`（只作依据，不参与生成）。
与前两份冲突时，**对白、说话人编号、音色绑定这三块以本说明为准**，其余照旧。

## 1. 说话人编号

- 按**首次发声**的先后给稳定编号 `(S1)`、`(S2)`……，整段里同一个人始终是同一个号。
- 多人同时说或齐声喊，用合并号 `(S1,S2)`。
- **不出声的角色不给编号**。出现在画面里不等于是说话人。
- 编号跟着「谁在说」走，不跟着 `<Subject N>` 的序号走，两者可以不一致。

## 2. 台词怎么写

```
<Subject 1> (S1) 低头，拇指仍按在她腕侧，轻声说：<d>[中文]宝宝，四十分钟。</d>
```

- 台词本身放进 `<d>[语言]原话</d>`，**一字不改、标点不改、不要翻译**。语言标记写实际语言（`[中文]` / `[English]`）。
- `<d>` 里**只放要说出口的字**。说话人是谁、什么表情、什么动作、语气轻重，一律写在 `<d>` 外面。
- 某个说话人**第一次开口**时，在 `<d>` 外面把身份立起来：是哪个 `<Subject N>`、性别年龄感、音高与音色、语速、在不在画面里。之后不再重复。
- 分镜信息的「台词」字段是唯一来源。写着「无」或空着，就**不要编台词**，也不要把剧本里别处的对白搬过来。

## 3. 画外音与内心独白

- 画外音固定用 `says in an off-screen voiceover`，并在该 `<d>` 之后**紧接着**说明这个角色嘴唇保持闭合，否则模型会让他对口型。
- 内心独白注明 `inner monologue, lips not moving`。

## 4. 台词跨镜头

- 一句话跨过剪辑点：在前后两个镜头的衔接处都写 `<scenetrans>`，并明确说声音连续（`continues seamlessly across the cut`）。
- 话没说完就到片尾：用 `<cutoff>`。

## 5. 音色参考（`<Audio N>`）

- 有 `<Audio N>` 时，在 `subject_definitions` 里写成：
  `<Audio 1> is the voice reference of <Subject 2> (S1).`
  一段音频只对应一个说话人；括号里的号取全局说话人编号，不另起一套。
- `retention_analysis` 对应行写 `<Audio 1>: fully_preserved - voice timbre of <Subject 2> (S1) is retained.`
- 有音色参考的角色开口时，**不要再描述他的嗓音特征**——音色由音频决定，文字描述只会打架。
- 没有音色参考的说话人，才用一句话交代嗓音。
- 输入里没给某段音频，就不要凭空写 `<Audio N>`。

## 6. 只锁该锁的

一张完成度高的参考图同时带着身份、环境、构图、姿势、光线和风格。**不要默认全锁**，否则每个镜头都会被拽回参考图那一个姿势。逐项决定：

| 维度 | 该锁的时候 |
|---|---|
| 身份（长相、服装、道具外观） | 几乎总是锁——这是参考图存在的理由 |
| 环境 | 锁「是哪个地方」，不锁「从哪个机位看」 |
| 构图 / 姿势 | 只有分镜信息明确要求时才锁 |
| 动作 / 运镜 / 节奏 | 只有确实要照搬时才锁 |
| 风格 | 用文字描述就够，别为此再加一张风格参考 |

保住「是谁、在哪」，把机位、站位、距离、微表情留给模型自己解决。

## 7. 镜头转换用时间码

- 分镜信息里出现视角、景别或位置的转换时，用 `[Shot N] At MM:SS.mmm,` 把它拆成内部镜头，时间严格递增。
- **一个 3~15 秒的片段永远只生成一条视频**。镜头是这条视频内部的剪辑区间，不是分开生成再拼。参考图多、镜头多、切得快，都不构成拆成多次生成的理由。
- 最多 4 个 `[Shot N]`。切太多次 H3 会糊。

## 8. 取舍顺序

信息塞不下时按这个顺序放弃，从后往前砍：

1. 台词原文、画面里必须出现的内容、指定的首尾帧；
2. 人物身份、道具数量、场景这些连续性不变量；
3. 这一镜的主导动作或情绪转折；
4. 运镜质感、装饰性转场、次要手势、微小的时间点。

先砍第 4 条。宁可把两个次要动作并成一个，也不要靠堆「不要……」来解决。

## 9. 语言

字段名、`<Picture N>` / `<Subject N>` / `<Audio N>` / `<d>` / `<scenetrans>` / `<cutoff>` / `(S1)` 这些标记、
`fully_preserved` 这类关系值，一律保持英文原样。
描述性文字用简体中文。`Tracking Shot`、`Push In`、`whip-pan` 这类摄影术语可以留英文。
台词和画面里可见的文字保持原文。
