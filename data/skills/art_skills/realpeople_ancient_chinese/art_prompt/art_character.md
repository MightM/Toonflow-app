# 人物基础形象（多视图人物需求）生成 · 约束手册


---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，毛孔级精细渲染
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **多视图为锚** — 一张人物多视图（主大头照 + 正/侧/背全身）同时锁定面容、体型、发型和基础服装，是分镜与视频引用的唯一形象
4. **冷艳含情** — 无妆状态仍需体现角色气质（清冷/温润/妩媚）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 古风真人写实摄影、毛孔级精细渲染、自然光照、物理光影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如清冷/温润/妩媚/侠骨），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/朝代/职业/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式礼服/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 闺秀/小姐 | 素色古装长裙（轻柔飘逸） |
| 公子/书生 | 素色古装长衫 |
| 武将/侠客 | 轻便武服 / 战袍便装 |
| 平民/市井 | 朴素短打 / 粗布衣裙 |
| 宫女/丫鬟 | 简朴宫装 / 婢女装束 |
| 角色描述未明确 | 素色古装常服（按性别匹配长裙/长衫） |

### 着装统一规则

- 服装风格须与古风真人写实美学一致（中国传统色调、写实材质）
- 颜色低饱和，无复杂花纹/装饰，便于后续衍生叠加
- 服装写到下装与鞋款（款式、颜色、材质，如：素色长裙+绣鞋、长衫+布靴），全身三视图要完整展示
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 七、输出：人物需求正文

> 系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（16:9 多视图拼图：主大头照 + 正面/侧面/背面全身、纯白背景、构图比例与一致性要求）。所以你**只写人物本身**，不要写排版、背景、视图、比例、镜头位置，也不要写「四视图」「定妆照」「拼图」之类的字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【人物需求】标签本身 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；手持道具 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 身份与造型 | 名字、年龄、身份、性格气质；所处朝代/时代与处境；发型；服装从上装写到下装和鞋款；面料材质 | 着装按第六节「着装选择原则」选，中国传统色调低饱和、无复杂花纹；发型按第五节，写明「无发冠、无发饰、无配饰」；明确去除与设定冲突的元素（如「无现代标识」） |
| 第二段 · 锁定脸部身份 | 「锁定同一张可复用的{年龄}{性别}脸部身份：」开头，依次写脸型、额头与发际线、颧骨、下颌与下巴、眼型与瞳色、眼距与眼皮、眉、鼻梁与鼻头、嘴唇与人中、耳朵、肤色肤质、身高体型 | 五官由角色描述推导，具体到可复现（例如「眼距约一只眼宽」「下巴略方微收」）；肤质按第三节写，并写「素颜无妆，保留毛孔与细小汗毛，无磨皮」；身高与头身比按第四节换算表写 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态 | 结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 本风格的写实质感锚词、主色调、光线 | 写「写实影视人物摄影质感，保留真实皮肤毛孔、虹膜、自然发丝、衣物缝线和面料纹理」；主色取服装的中国传统色；柔和均匀商业影棚布光，清晰高分辨率；避免塑料感、蜡像感、夸张卡通感、3D 渲染/CG 感 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态 |
| R2 | 必须根据角色描述声明合适的常规古装着装作为基础服装（如闺秀→素色长裙、书生→素色长衫、武将→轻便武服），并写到下装与鞋款；禁止内衣打底 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须声明角色身高并通过头身比换算约束全身比例（女性默认160-170cm/7-8头身，男性默认175-185cm/7.5-8.5头身） |
| R5 | 第二段必须逐项锁定脸型与五官，具体到可复现 |
| R6 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R7 | 第四段必须包含本风格锚词（写实影视人物摄影质感 / 真实皮肤毛孔 / 自然发丝 / 面料纹理）与影棚布光 |
| R8 | 只输出四段正文，不输出任何排版、背景、视图说明 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度美白至无血色 / 肤色发灰；塑料感、蜡像感、3D 渲染/CG 感 |
| X4 | 写排版/背景/视图/比例/镜头机位，或出现「四视图」「定妆照」「拼图」「多视图」字样（这些由系统模板负责） |
| X5 | 夸张表情/动态姿势；场景环境叙事；手持道具 |
| X6 | 忽略身高和头身比约束，身高必须明确声明并通过头身比换算体现全身比例 |
| X7 | 输出标题、编号、表格、解释等正文以外的内容 |
