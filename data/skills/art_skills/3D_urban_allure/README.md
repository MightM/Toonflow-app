# 都市魅惑 · 超写实3D真人

本风格专为"成熟都市情感 · 荷尔蒙魅惑"题材打造，所有美术提示词、规范和生成内容均限定于：

- **现代都市世界观**：以现代都市为背景，夜店、酒吧、酒店套房、顶层公寓、晚宴、雨夜街头、豪车内为主，也覆盖家庭客厅、卧室清晨、写字楼、医院、地下车库、废弃仓库等剧情需要的日常与冲突空间，强调夜晚与灯光。
- **超写实3D真人渲染**：所有角色、场景、道具以超写实 3D CG 真人渲染为标准——接近真人、肤质细腻带光泽、光影戏剧化，呈现高端 CG 海报级质感。
- **荷尔蒙美学**：通过合身剪裁的服装、露肤、撩人姿势、贴身接触、迷醉灯光、眼神与姿态张力，让观众直接感受成熟男女的身体线条与诱惑；情绪要拍出来，不靠转场留白。
- **人各有貌**：主角、配角、路人在脸型、肤色肤质、体型、年龄感、发型上必须拉开差距，观众一眼能分清谁是谁。
- **性感但非色情**：只守两条底线——未成年角色不性感化，不直接画出生殖器、女性乳头与性交动作；其余按剧情如实呈现。

## 适用范围

- 成熟都市情感、暧昧拉扯、豪门恋爱、夜生活、胁迫与救援、家庭伦理等题材的 AI 美术生成（角色、场景、道具、分镜、视频）
- 需要高辨识度人物、电影级夜色灯光、强烈情绪张力的视觉创作

## 允许内容

- 露肤：锁骨、肩背、腰腹、大腿、臀腿曲线、乳沟、后背全露都可以；内衣、睡衣、浴袍、泳装、湿身、oversize 衬衫作为居家或私密场景的服装
- 服装：包臀裙、超短裙、吊带丝缎裙、露背/高开衩礼服、亮片裙、夜店装、深V、丝袜、吊带袜、高跟鞋；男性敞领衬衫、贴身西装、背心、赤裸上身
- 姿势与动作：撩人姿势、暗示动作、贴身耳语、坐上大腿、抵墙、床上相拥、隔衣或贴肤抚摸、脱去外衣/解扣/褪下肩带、深吻、被扑倒、压制、挣扎、掐颈、撕扯衣物、扇耳光、抱起、拉进怀里
- 剧情情境：胁迫、绑架、暴力威胁、英雄救美、复仇、伤痕、血迹、酒醉、失控
- 家庭与日常：角色的子女、父母、同事、路人；未成年角色按日常、家庭、校园方式呈现
- 灯光：霓虹溢光、暖钨丝灯、烛光、百叶窗光影、烟雾体积光、家庭暖光、冷白硬光、地下车库顶灯

## 严禁内容（仅此几条）

- **未成年角色的性感化**：未成年角色可以出现，但不穿暴露服装、不出现在亲密/撩人/暗示画面中、不与成年人的亲密戏同框

- 卡通、动漫、二次元、插画风格；古风/古装/传统建筑

在本风格下，您将体验到：
