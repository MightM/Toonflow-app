### 情绪色盘使用规则

| 编号 | 规则 |
|---|---|
| E1 | 每条提示词至少指定 1 个「情绪场景」并绑定主色+辅色组合 |
| E2 | 单镜头主色不超过 2 个，霓虹色只做点缀 |
| E3 | 情绪切换时优先调整光比与色温，再调整饱和度 |
| E4 | 默认遵循「暗底 + 暖肤 + 高光点」：暗部铺底，暖光落在人物肌肤与视线焦点 |
| E5 | 若与剧情冲突，以情绪色盘优先于通用推荐色，但不得突破严禁项 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 夜景偏冷 4200-5000K，人物暖光 3000-3800K | 冷环境 + 暖人物的魅惑反差 |
| 肤色色温 | 暖 3200-4000K（推荐） | 肌肤温暖有血色 |

### 容差与例外

| 项目 | 建议容差 |

| 色相偏移 | ±10° |

| 明度偏移 | ±15% |

> 例外场景：日间办公、清晨、晚宴等明亮场景可提高整体明度，但仍需保留肌肤光泽与高光材质。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「超写实3D真人渲染」风格锚定词（hyperrealistic 3D render / photorealistic CG） |
| R2 | 必须声明「电影级灯光 + 极致细节」 |
| R3 | 面部必须使用「面容细腻渲染 + 肌肤细腻光泽」，并写出**这个角色自己的**辨识特征；不要用「完美面容」把所有人写成同一张脸 |
| R4 | 皮肤必须使用「次表面散射 + 自然肌肤光泽」，禁止塑料假面；允许并鼓励保留毛孔、雀斑、痣、细纹、胡茬、疤痕、晒痕等真实肤感差异 |
| R5 | 发丝必须使用「根根分明 + 发丝细腻渲染」 |
| R6 | 纹理必须声明「材质纹理超清晰」（丝缎/亮片/皮革/丝袜/金属/玻璃/棉麻/牛仔） |
| R7 | 含人物的提示词必须写明年龄段与年龄感：成年角色写「{年龄}岁{女性/男性}」并给出与年龄相符的面容与体态（22 岁和 45 岁不能是同一张脸）；未成年角色（子女、学生等）写「{年龄}岁{女孩/男孩/少年/少女}」，以日常、家庭、校园的方式呈现 |
| R8 | **角色差异化**：同一部剧里每个角色至少有 3 个一眼可辨的外貌锚点（脸型骨相 / 肤色肤质 / 体型身高 / 发色发型 / 标志性特征），主角、配角、路人不得共用同一套「标准美人脸 + 标准身材」模板；多人同框时逐一写清各自的区分点 |
| R9 | 情绪必须外化成身体语言、表情、姿势与光线，可以直接写撩人姿势、暗示动作、贴身接触、恐惧与挣扎；不要为了「含蓄」把戏剧动作换成空镜或转场 |
