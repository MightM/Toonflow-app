# 场景衍生资产生成 · 都市魅惑约束手册

---

## 一、衍生原则

1. **空间一致** — 建筑结构/布局/材质在所有变体中保持一致
2. **景别驱动** — 同一场景通过不同景别展示不同叙事功能
3. **灯光切换** — 同一空间在不同时段、不同灯光方案下呈现不同情绪（本风格最重要的衍生维度）
4. **天候变化** — 雨、雾等天候强化夜色氛围
5. **3D 写实为锚** — 所有变体保持超写实 3D 渲染质感、材质高光与氛围元素

---

## 二、时段与灯光变体

### 灯光方案定义

| 方案 | 视觉特征 | 提示词 |
|---|---|---|
| 午夜霓虹 | 冷蓝底 + 洋红/紫边缘光、烟雾染色 | 霓虹溢光、彩色烟雾 |
| 暖钨丝低调光 | 大面积暗部、暖光局部照亮 | 暖钨丝灯、低调光 |
| 烛光 | 摇曳暖光、柔和光斑 | 烛光摇曳、暖色光斑 |
| 百叶窗切光 | 条纹光影投在墙面与家具 | 百叶窗条纹光影 |
| 雨夜反射 | 湿润表面、倒影、雨滴折射 | 雨夜倒影、湿润反光 |
| 黄昏金光 | 金色低角度光、长影、天际渐变 | golden hour、金色余晖 |
| 清晨纱帘 | 柔和逆光、低对比、空气通透 | 纱帘逆光、柔和晨光 |
| 灯光熄灭（仅应急/月光） | 月光冷蓝、极暗、剪影轮廓 | 月光冷辉、极暗环境 |

### 灯光衍生规范

| 从基准衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间 → 夜间 | 建筑/布局/材质 | 整体压暗，开启灯带/壁灯/霓虹，增加城市灯火 |
| 暖光 → 霓虹 | 空间结构、家具 | 色温转冷，加入洋红/紫边缘光与烟雾 |
| 夜间 → 清晨 | 空间结构、家具 | 关闭人工光，纱帘逆光，低对比柔和 |
| 正常 → 凌乱（剧情需要） | 空间结构 | 散落的酒杯、滑落的外套、凌乱床品（不得出现内衣等暗示物） |

## 三、天候变体

| 天候 | 视觉特征 | 提示词 |
|---|---|---|
| 晴朗星夜 | 天际线清晰、灯火通透 | 晴朗夜空、城市灯火 |
| 细雨 | 雨丝、湿润反光、窗面雨滴 | 细雨如丝、玻璃雨滴 |
| 薄雾 | 光晕扩散、远景朦胧 | 薄雾弥漫、光晕扩散 |
| 暴雨（剧情需要） | 雨幕、闪电冷光 | 暴雨雨幕 |

| 从基准天候衍生 | 保持不变 | 变化项 |
|---|---|---|
| 晴 → 细雨 | 建筑/布局 | 增加雨丝、地面倒影、窗面水珠 |
| 晴 → 薄雾 | 建筑/布局 | 光源光晕扩大、远景降对比 |

## 四、风格词参考

> 下面是本风格原来的单图提示词模板，**只从中取画风、质感、光影、材质用词**写进正文，不照抄它的结构和字段。浅景深、散景、虚化、暗角这类镜头词不要写：三视图要求各个视图都清晰。

```
现代都市夜色衍生场景图，基于参考图，
超写实3D渲染，hyperrealistic 3D render，photorealistic CG，ray tracing，global illumination，physically based materials，
cinematic lighting，moody atmosphere，volumetric light，light haze，
shallow depth of field，bokeh，anamorphic lens flare，subtle vignette，
scene derivative design sheet，environment concept art，no people，no characters，no human figures，
保持场景空间结构一致，
{目标角度（如有）}，{景别视角（如有）}，{灯光方案/时段（如有）}，{天候描述（如有）}，
{前景}，{中景}，{后景}，
{情绪色盘主色+辅色}，{灯光描述}，{氛围元素：烟雾/雨丝/光束/倒影（如有）}，
{材质表面变化（如有）}，材质高光反射，材质纹理超清晰，空气透视，
画面中无任何人物
图中不要有任何文字
```

> **使用说明**：根据用户提供的信息自行判断需要应用的变化维度（角度/景别/灯光/天候），未提及的维度对应字段留空省略即可。

## 五、风格约束

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构在所有变体中保持一致 |
| R2 | 灯光变体必须同步调整色温、暗部比例与反射 |
| R3 | 天候变体必须适配材质表面（湿润、水珠、雾气） |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 未提及的变化维度留空省略 |
| R7 | 必须包含超写实 3D 渲染关键词与至少一项氛围元素 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 变体间建筑结构/布局不一致 |
| X2 | 变体间材质/风格突变 |
| X3 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X5 | 霓虹色铺满画面、光照平均无暗部 |
| X6 | 散落内衣、成人用品等情色暗示陈列 |

## 六、输出：场景变体需求正文

> 系统会把你的输出放进「【场景需求】」一节，并以父场景当前图（通常是三视图）为参考图1，开头写明「保持场景本体不变」，末尾追加固定的三视图【输出格式】。所以你**只写这个变体与参考图的差异和变化后的样子**，不写版式、视图、镜头。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出三段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【场景需求】标签本身 |
| 禁止内容 | 版式 / 视图 / 镜头焦段 / 画面比例；任何人物、人影 |
| 篇幅 | 全文约 250–500 字 |

### 三段结构

| 段落 | 写什么 |
|---|---|
| 第一段 · 变化 | 以「与参考图相比只改变：」开头，写清时段、天气、灯光方案、陈设增减或损毁程度的具体变化，以及变化出现在哪些位置 |
| 第二段 · 保持不变 | 以「保持不变：」开头，列出空间结构、出入口、主要陈设与道具的位置和数量、核心区域 |
| 第三段 · 变化后的光色与画风 | 变化后主光方向、2–3 个主色、材质表面随之出现的变化（湿润、积雪、焦痕、灰尘…）、可见氛围；本风格的画风锚词；以「无人物、无文字」结尾 |

### 输出约束

| 编号 | 规则 |
|---|---|
| O1 | 只输出三段正文，不输出版式、视图、镜头说明 |
| O2 | 未提到要变的维度一律写进「保持不变」 |
| O3 | 灯光或时段变化必须同步写出新的主光方向与主色 |
| O4 | 场景中不出现任何人物、人影、人体轮廓 |
| O5 | 不出现「三视图」「拼图」「单画面」「俯视」「近景」等取景字样 |
