# 人物基础形象（多视图人物需求）生成 · 都市魅惑约束手册

---

## 一、基础形象原则

1. **完美面容** — 五官是角色唯一锚点，完美比例 + 毛孔级精细渲染，拒绝千人一面
2. **成年气质** — 所有角色为成年人（设定年龄 ≥ 22 岁），面容与体态必须体现成熟魅力
3. **身形之美** — 身材匀称、线条优美，是本风格的核心卖点之一
4. **角色为本** — 基础着装由角色身份决定，但统一为合身、显身形的都市时髦版本；特定服化为后续叠加层
5. **多视图为锚** — 一张人物多视图（主大头照 + 正/侧/背全身）同时锁定面容、体型、发型和基础服装，是分镜与视频引用的唯一形象
6. **3D 写实** — 以超写实 3D 真人渲染为锚点，肌肤细腻有光泽，保留次表面散射的血色感

---

## 二、面容约束

> 不固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 生成完美但有辨识度的五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述推导，比例完美、立体精致，保留角色辨识度 |
| 风格底色 | 超写实3D真人渲染、面容细腻渲染、次表面散射、电影级光影 |
| 气质 | 必须从角色描述提炼气质关键词（如妩媚/冷艳/慵懒/清冷御姐/痞帅/禁欲/斯文败类），并写入提示词 |
| 年龄感 | 成熟面容，禁止童颜、幼态、婴儿肥 |
| 表情 | 中性微表情，眼神有故事感（可微带慵懒或清冷） |

## 六、基础服装约束

> 基础服装是角色的「日常默认态」：由身份决定款式，但统一采用合身、能展现身形线条的都市时髦版本；礼服、夜店装等在服化衍生环节叠加。**禁止内衣、泳装、睡衣作为底模服装**。

### 着装选择原则

| 角色身份 | 默认着装方向（女） | 默认着装方向（男） |
|---|---|---|
| 职场精英 | 修身衬衫 + 高腰包臀半裙 + 细跟高跟鞋 | 合身衬衫（解开领口一粒扣）+ 西裤 |
| 总裁/豪门 | 修身西装外套 + 吊带内搭 + 高腰阔腿裤/半裙 | 定制贴身三件套西装 |
| 自由职业/艺术 | 露肩针织上衣 + 高腰短裙 | 黑色贴身 T 恤 + 休闲西裤 |
| 夜场/调酒师/歌手 | 吊带背心 + 皮质短裙 | 黑衬衫挽袖 + 马甲 |
| 医生/律师等职业 | 对应职业装的合身版本 | 对应职业装的合身版本 |
| 角色描述未明确 | 修身针织吊带 + 高腰半裙 | 合身衬衫 + 西裤 |

### 着装统一规则

- 剪裁合身、突出腰线与肩线，面料带自然光泽（丝缎/针织/精纺羊毛/皮革）
- 露肤限于锁骨、肩颈、手臂、小腿；底模阶段不做深V、露背、超短等强露肤
- 颜色以丝缎黑、酒红、香槟、珍珠白等为主，无复杂花纹，便于后续衍生叠加
- 服装写到下装与鞋款（款式、颜色、材质），全身三视图要完整展示
- **严禁**校服/学生装、内衣、泳装、透视装作为底模

## 七、输出：人物需求正文

> 系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（16:9 多视图拼图：主大头照 + 正面/侧面/背面全身、纯白背景、构图比例与一致性要求）。所以你**只写人物本身**，不要写排版、背景、视图、比例、镜头位置，也不要写「四视图」「定妆照」「拼图」之类的字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【人物需求】标签本身 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；手持道具 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 身份与造型 | 名字、年龄（≥ 22 岁）、身份、性格气质；所处时代与场合；发型；服装从上装写到下装和鞋款；面料材质；配饰 | 着装按第六节「着装选择原则」选；写清颜色与材质；明确去除与设定冲突的元素（如「无现代标识、无夸张首饰」） |
| 第二段 · 锁定脸部身份 | 「锁定同一张可复用的{年龄}{性别}脸部身份：」开头，依次写脸型、额头、颧骨、下颌与下巴、眼型与瞳色、眼距与眼皮、眉、鼻梁与鼻头、嘴唇与人中、耳朵、肤色肤质、体型身材 | 五官由角色描述推导，具体到可复现（例如「眼距约一只眼宽」「下巴短而圆润」）；肤质写「保留毛孔与细小汗毛，无磨皮」；体型按第四节写身高感与头身比 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态 | 结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 本风格的渲染锚词与质感、主色调、光线 | 用本手册的风格锚词：超写实3D真人渲染、hyperrealistic 3D render、photorealistic CG、次表面散射、面料高光反射；柔和均匀的商业影棚布光；避免塑料感、蜡像感、过度磨皮 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明角色为成年人并写明年龄（≥ 22 岁）与成熟气质 |
| R2 | 必须根据角色身份声明合身的都市常规着装，并写到下装与鞋款 |
| R3 | 第二段必须逐项锁定脸型与五官，具体到可复现 |
| R4 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R5 | 第四段必须包含本风格锚词（超写实3D真人渲染 / 次表面散射 / 面料高光反射）与影棚布光 |
| R6 | 只输出四段正文，不输出任何排版、背景、视图说明 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/泳装/睡衣/透视装/校服作为底模；深V、露背、超短等强露肤放到衍生环节 |
| X2 | 童颜、幼态、娇小未成年体态、学生身份描述 |
| X3 | 身材比例夸张畸形（巨乳细腰漫画化、腿长失真） |
| X4 | 塑料假面、过度磨皮、蜡像感 |
| X5 | 写排版/背景/视图/比例/镜头机位，或出现「四视图」「定妆照」「拼图」「多视图」字样（这些由系统模板负责） |
| X6 | 撩人姿势、动作描写、场景环境叙事、手持道具 |
| X7 | 输出标题、编号、表格、解释等正文以外的内容 |
