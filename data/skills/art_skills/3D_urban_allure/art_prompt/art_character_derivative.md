# 人物衍生资产（衍生多视图人物需求）生成 · 都市魅惑约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模（父角色多视图，即参考图1）完全一致，禁止面容偏移
2. **身形不变** — 身高、头身比、身材线条与底模一致，服装只负责"展示"身形
3. **姿态不变** — 全身视图保持自然站立，禁止任何姿态/动作/体态变化
4. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
5. **魅惑有度** — 露肤强度按场合分档，始终不越过内容边界
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 父角色的多视图（参考图1），脸部身份与体型不修改 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「基础妆/约会妆/夜场妆」强度 |
| L2 | 发型造型 | 发型设计 + 发饰 |
| L3 | 内搭 / 丝袜 | 吊带、抹胸式内搭（非内衣）、丝袜、打底 |
| L4 | 主服 / 外衣 / 鞋履 | 包臀裙、短裙、吊带丝缎裙、礼服、西装、高跟鞋等 |
| L5 | 配饰 | 耳饰/项链/锁骨链/脚链/手镯/腕表/腰链 |

> **范畴边界**：人物衍生资产仅包含 L0–L5（服化妆造），不包含道具（酒杯/手机/包/烟等手持物）、场景环境、姿态动作。

## 八、输出：衍生人物需求正文

> 衍生资产以**父角色的多视图**为参考图（参考图1）生成新的多视图。系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（主大头照 + 正面/侧面/背面全身、纯白背景等）。所以你**只写人物本身**：身份锁定 + 新的服化妆造 + 表情 + 画风；不要写排版、背景、视图、比例，也不要出现「四视图」「定妆照」「拼图」等字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、分层方案、速查表、Markdown 符号、代码块、解释说明 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；手持道具（酒杯/手机/包/烟等）；姿态动作 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 |
|---|---|
| 第一段 · 身份锁定与新服化 | 固定以「以参考图1中人物为唯一脸部身份母版，保持骨相五官、发际线、肤色与体型不变，只替换服化妆造：」开头；然后按 L1→L5 写：妆容（先按第三节决策档位）、发型与发饰、内搭/丝袜、主服与鞋履（写到下装和鞋款，注明露肤档位内的露肤部位）、配饰；写清颜色与材质 |
| 第二段 · 脸部身份复述 | 用 2–4 句复述父级描述里的关键脸部特征（脸型、眼型、鼻唇、肤色、体型），强调与参考图1完全一致 |
