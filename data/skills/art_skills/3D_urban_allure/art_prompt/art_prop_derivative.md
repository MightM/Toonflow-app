# 道具衍生状态生成 · 约束手册（都市魅惑版）

---

## 一、衍生原则

1. **造型锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异一目了然，观众能立即区分
3. **叙事服务** — 每种状态服务于特定剧情节点（邀约、争执、离开、余温）
4. **质感不降** — 任何状态下材质高光与精致感保持

---

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 完好无损、光泽如新 | 所有道具 | 崭新、光泽如新 |
| 使用中痕迹 | 杯中余酒、口红印、香水余量 | 酒杯/口红/香水 | 杯沿口红印、半杯余酒 |
| 余温 | 冰块半融、烛泪、烟雾余缕 | 酒杯/蜡烛/打火机 | 冰块半融、烛泪凝固 |

### 2.2 情绪痕迹状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 倾倒 | 酒杯倾倒、酒液流淌 | 酒杯/醒酒器 | 酒杯倾倒、酒液蔓延 |
| 碎裂 | 玻璃/水晶碎裂 | 酒杯/香水瓶/镜子 | 玻璃碎裂、碎片折光 |
| 遗落 | 单只高跟鞋、滑落的丝巾、遗落的耳坠 | 鞋履/丝巾/首饰 | 单只遗落、丝巾垂落 |
| 断裂 | 项链断开、鞋跟折断 | 首饰/高跟鞋 | 项链断开、鞋跟折断 |

### 2.3 特殊状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 水珠 | 杯壁凝结水珠、雨滴 | 酒杯/手机/车钥匙 | 凝结水珠、雨滴附着 |
| 划痕 | 金属/屏幕划痕 | 打火机/手机/腕表 | 细微划痕 |
| 屏幕亮起 | 来电/消息亮屏（无可读文字） | 手机 | 屏幕亮起、柔和屏光 |

## 三、材质状态变化规则

| 材质 | 崭新 → 使用 | 使用 → 痕迹 | 损伤表现 |
|---|---|---|---|
| 水晶/玻璃 | 通透 → 水珠/口红印 | 残酒干涸 | 碎裂/缺口 |
| 金属 | 抛光 → 指纹微痕 | 细划痕 | 凹陷/断裂 |
| 漆皮/皮革 | 镜面 → 微折痕 | 折痕加深 | 鞋跟折断/撕裂 |
| 丝缎/丝巾 | 平整 → 自然褶皱 | 凌乱褶皱 | 勾丝/撕裂 |
| 蜡烛 | 完整 → 燃烧中 | 烛泪凝固 | 熄灭残烟 |

## 四、风格词参考

> 下面是本风格原来的单图提示词模板，**只从中取画风、质感、光影、材质用词**写进正文，不照抄它的结构和字段。浅景深、散景、虚化、暗角这类镜头词不要写：三视图要求各个视图都清晰。

### 单状态变体

```
基于{道具名}设定图，超写实3D渲染，hyperrealistic 3D render，电影级灯光，极致细节，
{道具类型}，{材质描述}，
当前状态：{状态名}，{状态视觉描述}，
{材质表面变化描述}，材质高光保持，
纯净深灰背景，柔和主光与轮廓光，无硬阴影，
材质纹理超清晰，质感奢华，状态细节可辨
图中不要有任何文字，画面中不能出现任何人物、手部、肢体
```

## 五、风格约束

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合物理逻辑 |
| R4 | 必须指定「纯净深灰背景」 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤 |
| X3 | 血迹、暴力痕迹等超出情感剧范畴的状态 |
| X4 | 出现任何人物或肢体 |

## 六、输出：道具状态需求正文

> 系统会把你的输出放进「【道具需求】」一节，并以父道具当前图（通常是三视图）为参考图1，开头写明「保持物品本体不变」，末尾追加固定的三视图【输出格式】。所以你**只写这个状态与参考图的差异和变化后的样子**，不写版式、视图、背景。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出三段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【道具需求】标签本身 |
| 禁止内容 | 版式 / 视图角度 / 背景 / 布光；人物、手部、持握或佩戴状态 |
| 篇幅 | 全文约 200–400 字 |

### 三段结构

| 段落 | 写什么 |
|---|---|
| 第一段 · 状态变化 | 以「与参考图相比只改变：」开头，写清状态变化（打开、碎裂、点燃、染血…）的部位、程度与形态 |
| 第二段 · 保持不变 | 以「保持不变：」开头，列出外形比例、尺寸、部件与数量、颜色、纹样、原有痕迹 |
| 第三段 · 材质变化与画风 | 状态变化带来的材质表面变化（裂纹走向、焦黑边缘、液体反光…）；本风格的画风锚词；以「无人手、无文字」结尾 |

### 输出约束

| 编号 | 规则 |
|---|---|
| O1 | 只输出三段正文，不输出版式、视图、背景说明 |
| O2 | 状态变化必须写清部位与程度，三个角度都能对上 |
| O3 | 未提到要变的部分一律写进「保持不变」 |
| O4 | 不出现人物、人手、持握或佩戴状态 |
| O5 | 不出现「三视图」「四宫格」「正面图」「侧面图」等版式字样 |
