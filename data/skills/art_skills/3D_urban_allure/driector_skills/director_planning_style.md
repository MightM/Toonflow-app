# 都市风格约束 · 都市魅惑 · 超写实3D真人 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以丝缎黑（C2）、午夜蓝（C5）为暗部基底，蜜桃暖肤（C1）、香槟金（C4）、琥珀暖（C8）落在人物与高光处，形成「暗底 + 暖肤 + 高光点」的魅惑基调
- **冷暖叙事对比** — 暖光越靠近人物肌肤，情欲张力越强；冲突、疏离、危险段落降低暖光占比，转向午夜蓝与硬侧光
- **霓虹只做点缀** — 霓虹洋红（C6）、电光紫（C7）用于夜店、雨夜、车内等段落的边缘光与烟雾染色，面积不超过画面 20%
- **色盘先行原则** — 段落规划先绑定情绪场景（初遇对视/暧昧试探/夜店迷醉/酒店长廊/雨夜车内/晚宴高光/冲突对峙/清晨余温），再确定主色+辅色与光影方案
- **禁用色域** — 大面积荧光色铺满、平均无暗部的"白开水"照明、低饱和灰蒙蒙滤镜

## 二、光影方案体系

- **光影即欲望** — 6 套光影方案对应不同情绪段落，导演规划阶段在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 人物主光默认 45° 侧前方低调光，保留面部与身体一侧暗部；轮廓光从后侧勾勒发丝、肩线、腰线

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 霓虹溢光 | 午夜蓝底 + 洋红/紫边缘光 + 烟雾 | 夜店、派对、迷醉放纵 |
| B | 暖钨丝低调光 | 琥珀暖局部 + 大面积暗部 | 酒吧、套房、暧昧试探 |
| C | 百叶窗切光 | 条纹光影切割人物与空间 | 悬念、欲望与秘密 |
| D | 雨夜反射 | 冷蓝 + 霓虹倒影 + 暖色仪表光 | 车内、街头、私密心事 |
| E | 烛光近景 | 暖色摇曳光斑、柔和高光 | 晚餐、亲密、心动 |
| F | 晨光逆光 | 珍珠白纱帘逆光、低对比 | 清晨余温、温柔、和解 |
| G | 家庭暖光 | 客厅落地灯 + 暖白顶光，中等对比 | 亲子、家庭日常、父母长辈出场 |
| H | 胁迫冷光 | 冷白硬侧光 / 车库顶灯频闪 / 单一光源打在受害者脸上，大面积黑 | 胁迫、绑架、暴力威胁、救援前的绝望 |

- **补充方案** — 晚宴大场面可用水晶吊灯高光（明亮但保留材质反光）；打斗与救援可用手电/车灯扫光制造动感
- **氛围方向映射** — 每场戏氛围方向应映射到上述 A-H 某一方向，确保视觉一致性

## 三、质感方向

- **超写实3D真人渲染** — 接近真人但完美：面容比例完美、肌肤细腻带光泽、次表面散射血色、发丝根根分明
- **肌肤是主角** — 锁骨、肩头、颈线、腿部的高光与暗部过渡是画面焦点，禁止塑料假面与蜡像感
- **材质高光** — 丝缎流光、亮片闪烁、漆皮镜面、水晶折射、湿润地面倒影，每场戏至少一种高光材质
- **氛围层** — 烟雾、光束、散景光斑、宽银幕光斑让画面"有空气"，但不能糊掉主体
- **性感要拍出来** — 撩人姿势、暗示动作、贴身接触、内衣睡衣、脱衣与床上相拥都直接进画面；遮挡、剪影、转场只用在最后一步（生殖器、乳头、性交动作本身）
- **人各有貌** — 规划阶段就为主角、配角、路人分配不同的脸型、肤色、体型、发色与标志性特征，写进人物小传；观众靠外貌就能分清谁是谁

## 四、魅惑空间元素

- **镜面/玻璃/落地窗** — 倒影制造双重身影与窥视感，落地窗外的城市夜景衬托人物孤独与欲望
- **长廊/电梯/车内** — 封闭或纵深空间放大两人距离的变化，是张力戏的首选容器
- **吧台/卡座/床沿** — 情绪容器：吧台偏试探，卡座偏放纵，床沿偏私密与抉择
- **烟雾与光束** — 夜店与酒吧必备，用于分隔前后景并柔化肌肤
- **家庭与日常空间** — 客厅、餐桌、儿童房、学校门口、医院病房：用暖白光和生活道具区分于夜色段落，是子女、父母戏的容器
- **冲突与胁迫空间** — 地下车库、废弃仓库、后巷、私人会所包间、别墅地下室：单一光源、大面积黑、金属与水泥质感，放大恐惧
- **转折点用视觉而非解释** — 视线交汇、手指停在半空、高跟鞋停步、领带被松开、肩带滑落、门被踹开，都是转折信号

## 五、尺度与张力表达（全片）

- **只有两条底线**：① 未成年角色不性感化——子女、学生可以出场，但只在日常、家庭、校园段落，不进入亲密与暗示画面；② 不直接呈现生殖器、女性乳头与性交动作——到这一步用床单、手臂、头发、前景遮挡，或剪影、关门、灯熄、窗外夜景
- **亲密段落直接规划**：对视、耳语、坐上大腿、抵墙、深吻、扑倒在床、隔衣或贴肤抚摸、解扣、褪下肩带、脱去外衣、床单下相拥、事后相拥都可以写进段落大纲，不必用留白代替
- **胁迫与救援段落直接规划**：绑架、拖拽、压制、掐颈、撕扯衣物、扇耳光、恐惧与挣扎、破门救人、拳脚相向、血迹淤青都可以写；受害者的恐惧与反抗是张力来源，救援者的破门是情绪释放点，两者都要给足镜头
- **服装不设限**：内衣、睡衣、浴袍、泳装、湿身、撕破的衣物按剧情写进段落说明
- **情绪要调动得起来**：规划时明确每个段落要让观众产生的反应（心跳、脸红、揪心、解气、心疼），并说明用什么画面达成，不写「暧昧」「张力」这类空词

## 六、魅惑乐器与环境音

### 乐器选择

- **R&B / Neo-Soul 人声哼唱** — 暧昧、试探、慵懒段落的核心
- **萨克斯 / 小号（弱音）** — 酒吧、爵士夜、成熟男女对手戏
- **Deep House / 慢速电子** — 夜店、派对、迷醉段落
- **钢琴 + 弦乐** — 心动确认、情绪抬升、分离与和解
- **低频贝斯脉冲** — 危险、欲望压抑、悬念

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 开场/夜色建立 | 慢速电子 + 城市环境声 |
| 暧昧试探 | R&B 哼唱 + 低频贝斯 |
| 酒吧对手戏 | 萨克斯 + 钢琴 |
| 夜店高潮 | Deep House 主导 |
| 心动确认/分离 | 钢琴 + 弦乐 |
| 清晨余温 | 钢琴独奏 或 吉他独奏 |
| 胁迫/危险逼近 | 低频贝斯脉冲 + 弦乐颤音 + 金属打击 |
| 救援/反击 | 打击乐骤起 + 铜管 + 电子低频 |
| 家庭/亲子 | 木吉他 + 钢琴，轻打击乐 |

### 都市夜色环境音

- **典型环境音层次** — 高跟鞋踩在大理石上的声音 / 冰块碰杯 / 酒液倒入 / 夜店低频透墙 / 雨打车窗 / 打火机开合 / 丝缎摩擦 / 房卡开门提示音 / 电梯到达提示音 / 城市远景车流 / 车库回声与脚步 / 衣物撕裂 / 急促呼吸 / 门被踹开 / 儿童笑声与餐具碰撞
- **每场戏标注 1-2 个核心环境音**，其中至少一个是「贴近人物的细节音」（呼吸、布料、鞋跟、杯碰），增强私密感
