# 分镜表都市魅惑约束 · 超写实3D真人 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供都市魅惑风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **同场戏光影统一** — 一场戏内不应出现两种以上光影方案（A-H），除非有明确叙事转折（如关灯→窗外霓虹、夜→晨光、门被踹开车灯扫入）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景，镜头组内保持主色+辅色连续
- **光源角度规范** — 人物主光默认 45° 侧前方低调光，必须写明轮廓光位置（勾勒发丝/肩线/腰线）
- **暖光跟随亲密度** — 两人距离越近，暖光越集中在肌肤与面部；分开或冲突时暖光退场
- **光影转场是高级手段** — 霓虹闪烁明灭、烛光被吹灭、窗帘拉开晨光涌入，可在分镜表中标注光影变化点

## 三、张力镜头节奏

- **视线停留** — 关键对视镜头时长 ≥ 3 秒，给观众遐想时间；对视常用过肩镜头 + 反打特写
- **局部特写组合** — 每场张力戏至少安排 1 组局部特写：锁骨与项链、指尖划过杯沿、红唇、喉结滚动、高跟鞋落地、丝袜脚踝、领带被松开、裙摆扫过、肩带滑落、手指解开扣子、腰臀曲线、大腿与吊带袜边缘
- **先局部后整体** — 人物登场优先"高跟鞋落步 → 裙摆/腿部线条 → 腰臀 → 回眸面部"的由下至上揭示
- **慢节奏动作** — 亲密段落人物动作默认放慢：转身、撩发、倚靠、抬眼都标注"缓慢"或"慵懒"；胁迫、打斗、救援段落改为急促，标注"猛地""一把"
- **情绪顶点拍出来** — 深吻、扑倒、抚摸、解扣、撕扯、掐颈、破门都要有正面镜头；只有到生殖器、乳头、性交动作本身这一步才用转场留白（门合上、灯熄、镜头移向窗外夜景）
- **胁迫戏三段式** — 「威胁逼近（施暴者进入画面，受害者后退/被抵住）→ 失控（拖拽、压制、撕扯、恐惧特写、挣扎）→ 转折（救援者破门 / 反击 / 屈服的绝望）」，每段至少 2 个镜头，受害者的恐惧与反抗要有面部特写
- **救援戏节奏** — 破门或出手的镜头用短镜头快切，接一个把人拉进怀里或护在身后的长镜头，再接一个受害者情绪释放的特写
- **多人镜头点名区分** — 同框两人以上时，分镜描述里给每个人一个可辨特征（金发助理、刀疤壮汉、穿睡裙的女主），避免生成时脸重合

## 四、环境动态

- **环境动态增加呼吸感** — 每 3-4 个镜头至少一个环境动态：烟雾流动、霓虹闪烁、酒液倾倒、冰块旋转、雨滴划窗、烛火摇曳、丝质窗帘被风吹起、城市车灯流光
- **都市夜色元素优先** — 环境动态必须来自现代都市夜色世界观，禁止与本风格不兼容的元素

---

## 五、尺度与张力表达

- **两条底线**：未成年角色不性感化（子女、学生只出现在日常、家庭、校园镜头，穿日常童装，不与亲密戏同框）；不直接呈现生殖器、女性乳头与性交动作
- **其余照写**：内衣、睡衣、浴袍、泳装、湿身、撕破的衣物；撩人姿势、暗示动作、坐上大腿、抵墙、深吻、扑倒在床、隔衣或贴肤抚摸、解扣、褪肩带、脱去外衣、床单下相拥；胁迫、拖拽、压制、掐颈、撕扯、扇耳光、恐惧、挣扎、血迹淤青
- **局部特写不设禁区**：胸部曲线、臀腿、大腿根、腰腹都可以作为特写焦点，只要关键部位被衣物、床单或身体遮挡
- **拥吻与床戏镜头拆法**：「近景起势（额头相抵/抵墙）→ 局部特写（手贴腰际/解扣/肩带滑落）→ 全身或半身（扑倒/相拥倒向床）→ 局部与剪影（床单下的轮廓、交缠的手）→ 转场（灯熄/窗外）」，转场只放在最后一步
- **胁迫戏拍受害者视角**：恐惧、反抗、求救的面部特写与施暴者的压迫感并重，让观众揪心；不把胁迫过程拍成施暴者的炫耀

## 六、运镜与转场规范

- **亲密段落慢** — 缓推、缓拉、环绕、低角度跟随、焦点转移（前景酒杯 → 后景人物）、升格
- **胁迫与救援段落快** — 急推、手持晃动、甩镜、快切都可以用，节奏跟着恐惧和暴力走
- **机位不设禁区** — 低角度仰拍腿部与裙摆、俯拍乳沟与锁骨、窥视视角（门缝、百叶窗、后视镜、跟踪者视角）都可以用，只要服务于撩拨、悬念或威胁感
- **禁用花式转场** — 划屏、旋转、百叶窗特效转场等与本风格不兼容
