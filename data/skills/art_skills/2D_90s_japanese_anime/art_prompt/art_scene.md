# 90年代复古日系动画风格 - 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **质感至上** — 线条/色彩/光影等材质表现必须清晰
4. **90年代为锚** — 一切画面以90年代复古日系动画为标准，拒绝现代CG/3D渲染；追求手绘线条特征（流畅线条、块面阴影）与电影感光影（柔和暖光、体积光）

## 五、三视图说明（由系统负责）

> 系统会把你的输出放进「【场景需求】」一节，再自动追加固定的【输出格式】：横向三视图拼图，左侧高机位俯视全景、中间正面平视远景、右侧核心区域近景，三个视图是同一空间、同一时刻。
> 所以你**只写场景本身**：不写版式、视图、镜头焦段、画面比例，也不要写「三视图」「拼图」「单画面」「主视图」之类的字样。

## 七、风格约束

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含90年代关键词（90s anime style / hand-drawn / warm tone） |
| R7 | 必须包含线条特征（流畅线条、块面阴影 至少一项） |
| R8 | 材质必须带有使用痕迹，禁止全新无瑕的"CG 感" |

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影 |
| X7 | 3D 渲染/CG 动画/现代风格质感 |
| X8 | 材质过于干净完美、无任何使用痕迹 |
| X9 | 光照过于均匀平坦、无柔和电影光 |

## 八、输出：场景需求正文

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【场景需求】标签本身 |
| 禁止内容 | 版式 / 视图 / 镜头焦段 / 画面比例；任何人物、人影；剧情对白 |
| 篇幅 | 全文约 400–700 字 |

### 四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 定位与色彩 | 场景名与所属世界观、时代、题材；本风格的画面质感定位；季节与时段；主光从画面哪个方向来（如「自画面左后方洒落」）；2–3 个主色；构成空间肌理的主要元素 | 光线方向必须写死，三个视图靠它统一；主色用具体色名 |
| 第二段 · 锁定空间与陈设 | 以「锁定同一真实空间与陈设：」开头，按前景→中景→远景或左→右，写清主要结构、出入口与动线、固定家具 / 陈设 / 道具的位置、数量和朝向；标出留给人物表演的开阔区域 | 写到可复现（「数级宽阔石阶由步道下接水边」「船首悬两盏纸灯笼」）；数量、位置写死 |
| 第三段 · 材质、氛围与剧情用途 | 关键材质的质感与使用痕迹（石材湿润微反光、漆面磨损、铜件氧化…）；天气、空气、倒影、光晕等可见氛围；这里在剧情中用来发生什么，以及由此带来的空间特征（近水危险、狭窄压迫、开阔对峙…） | 氛围要能被看见，不写抽象情绪词堆砌 |
| 第四段 · 核心区域与画风 | 「核心区域：」写最能承载剧情动作的一处及其细节；「空间锚点：」写近处也能看到的 1–2 个可识别元素；最后写本风格的画风质感锚词（取自「风格词参考」），并以「无人物、无文字」加上与世界观冲突的排除项结尾 | 核心区域必须是第二段里已经写过的位置 |

### 示例（仅示意写法；画风锚词与世界观按本手册与剧情来写）

```
金陵玄武湖畔的开阔湖岸，架空华朝古装武侠轻喜剧里的江南场景，写实影视质感。秋日傍晚，暮金色斜阳自画面左后方洒落，整体以湖水青碧、暮金、墨黑为主色；青瓦白墙的临湖建筑、朱栏画舫、垂柳与石阶构成古典生活肌理。

锁定同一真实空间与陈设：沿湖石砌步道自前景延向中远景，数级宽阔灰青石阶由步道下接水边；石阶右侧系泊一艘朱栏乌篷画舫，船头朝向画面左侧；左侧成排垂柳枝条拂过湖面，远处是竹影、白墙黛瓦和层叠湖岸。步道中央留出一片开阔空地，供聚会与对峙。

石材湿润微反光，木质船身有清晰的漆面磨损与铜质系缆件，柳叶、竹木与水面质感真实；湖面有微风涟漪和画舫倒影，空气清透。这里用于才子聚会、理念交锋与落水冲突，环境平静雅致，但石阶近水、船舷紧贴湖面，构成明确的危险行动空间。

核心区域：临水石阶与画舫系泊处，湿润的灰青石阶纹理、水面涟漪、朱栏船舷的漆面磨损、铜质系缆件和垂落柳枝。空间锚点：湖岸步道与远处白墙黛瓦。写实电影级影视质感，清晰的石材与木材纹理，统一曝光与色彩；无人物、无文字、无现代元素、无夸张卡通感。
```
