# 90年代复古日系动画风格 - 场景衍生资产生成 · 约束手册

---

## 一、衍生原则

1. **空间一致** — 建筑结构/布局/材质在所有变体中保持一致
2. **景别驱动** — 同一场景通过不同景别展示不同叙事功能
3. **时段切换** — 同一空间在不同时间段呈现不同光影氛围
4. **天候变化** — 同一空间在不同天气下呈现不同情绪
5. **90年代为锚** — 所有变体必须保持90年代复古风格，拒绝现代CG/3D渲染

---

## 二、时段变体

### 时段定义

| 时段 | 视觉特征 | 提示词 |
|---|---|---|
| 清晨 | 薄雾柔光、色调偏冷 | 晨光、清晨薄雾 |
| 正午 | 明亮、阴影短、色彩鲜明 | 正午阳光、光线明亮 |
| 黄昏 | 金色色调、长影、天空渐变 | 黄昏、golden hour |
| 夜间（月光） | 冷蓝色调、幽静清冷 | 月光、月夜 |
| 夜间（灯火） | 暖黄点缀、明暗对比 | 夜晚、灯火 |

### 时段衍生规范

| 从基准时段衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间 → 黄昏 | 建筑/布局/材质 | 天空色调暖化、影子拉长 |
| 日间 → 夜间 | 建筑/布局/材质 | 整体变暗、增加灯火/月色 |
| 室内日间 → 室内夜间 | 空间结构、家具 | 整体色调暖化、增加光源 |

---

## 三、天候变体

### 天候定义

| 天候 | 视觉特征 | 提示词 |
|---|---|---|
| 晴天 | 明亮、阴影清晰 | 晴天、阳光明媚 |
| 阴天 | 光线均匀、无硬影 | 阴天、柔和光线 |
| 薄雾 | 能见度降低、空气朦胧 | 薄雾、雾气缭绕 |
| 细雨 | 水珠、湿润反光 | 细雨、雨丝 |
| 飞雪 | 白色覆盖、雪花飘落 | 飞雪、雪花 |

### 天候衍生规范

| 从基准天候衍生 | 保持不变 | 变化项 |
|---|---|---|
| 晴 → 薄雾 | 建筑/布局 | 增加雾气层、远景模糊 |
| 晴 → 细雨 | 建筑/布局 | 增加雨丝、地面反光 |
| 晴 → 飞雪 | 建筑/布局 | 增加积雪、雪花 |
| 植被需随天候逻辑适配 | — | 雨中植物湿润、雪中植物挂霜 |

## 四、风格词参考

> 下面是本风格原来的单图提示词模板，**只从中取画风、质感、光影、材质用词**写进正文，不照抄它的结构和字段。浅景深、散景、虚化、暗角这类镜头词不要写：三视图要求各个视图都清晰。

```
90年代复古日系动画风格衍生场景图，基于参考图，
90s anime style，手绘平涂上色，柔和暖色调，精细流畅线条，电影感光影，
scene derivative design sheet，environment concept art，no people，no characters，no human figures，
保持场景空间结构一致，
{目标角度（如有）}，{景别视角（如有）}，{时段描述（如有）}，{天候描述（如有）}，
{前景}，{中景}，{后景}，
{色调描述}，{景深描述（如有）}，{天空色调变化（如有）}，{氛围调整（如有）}，
{天候视觉特征（如有）}，{材质表面变化（如有）}，{植被适配描述（如有）}，
线条流畅、块面阴影、使用痕迹，
柔和电影光、背景光晕、自然光照，
画面中无任何人物
图中不要有任何文字
```

> **使用说明**：根据用户提供的信息自行判断需要应用的变化维度（角度/景别/时段/天候），未提及的维度对应字段留空省略即可。无需为每种变体单独生成模板。

## 五、风格约束

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构在所有变体中保持一致 |
| R2 | 时段变体必须调整天空色调与氛围 |
| R3 | 天候变体必须适配植被/材质表面 |
| R5 | 衍生图必须与参考图保持建筑结构/材质/色调/光线一致，仅按指定角度切换视点 |
| R6 | 场景图中**严禁出现任何人物** |
| R7 | 根据用户提供的信息自行判断变化维度（角度/景别/时段/天候），未提及维度留空省略 |
| R8 | 必须包含90年代关键词（90s anime style / hand-drawn / warm tone） |
| R9 | 必须包含线条特征（流畅线条、块面阴影 至少一项） |
| R10 | 材质必须带有使用痕迹，禁止全新无瑕的"CG 感" |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 变体间建筑结构/布局不一致 |
| X2 | 天候与季节矛盾 |
| X3 | 变体间材质/风格突变 |
| X4 | 出现任何人物、人影、人体剪影 |
| X6 | 3D 渲染/CG 动画/现代风格质感 |
| X7 | 材质过于干净完美、无任何使用痕迹 |
| X8 | 光照过于均匀平坦、无柔和电影光 |

## 六、输出：场景变体需求正文

> 系统会把你的输出放进「【场景需求】」一节，并以父场景当前图（通常是三视图）为参考图1，开头写明「保持场景本体不变」，末尾追加固定的三视图【输出格式】。所以你**只写这个变体与参考图的差异和变化后的样子**，不写版式、视图、镜头。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出三段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【场景需求】标签本身 |
| 禁止内容 | 版式 / 视图 / 镜头焦段 / 画面比例；任何人物、人影 |
| 篇幅 | 全文约 250–500 字 |

### 三段结构

| 段落 | 写什么 |
|---|---|
| 第一段 · 变化 | 以「与参考图相比只改变：」开头，写清时段、天气、灯光方案、陈设增减或损毁程度的具体变化，以及变化出现在哪些位置 |
| 第二段 · 保持不变 | 以「保持不变：」开头，列出空间结构、出入口、主要陈设与道具的位置和数量、核心区域 |
| 第三段 · 变化后的光色与画风 | 变化后主光方向、2–3 个主色、材质表面随之出现的变化（湿润、积雪、焦痕、灰尘…）、可见氛围；本风格的画风锚词；以「无人物、无文字」结尾 |

### 输出约束

| 编号 | 规则 |
|---|---|
| O1 | 只输出三段正文，不输出版式、视图、镜头说明 |
| O2 | 未提到要变的维度一律写进「保持不变」 |
| O3 | 灯光或时段变化必须同步写出新的主光方向与主色 |
| O4 | 场景中不出现任何人物、人影、人体轮廓 |
| O5 | 不出现「三视图」「拼图」「单画面」「俯视」「近景」等取景字样 |
