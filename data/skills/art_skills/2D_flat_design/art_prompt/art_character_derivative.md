# 人物衍生资产（衍生多视图人物需求）生成 · 扁平风约束手册

---

## 一、叠加原则

1. **轮廓不变** — 叠加后线条轮廓必须与底模（父角色多视图，即参考图1）完全一致，禁止轮廓偏移
2. **姿态不变** — 全身视图保持自然站立，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **风格统一** — 所有服化元素服从同一扁平美学体系
5. **色块不降** — 叠加后色块标准不低于底模
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 父角色的多视图（参考图1），脸部身份、轮廓与体型不修改 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「基础妆 / 轻妆 / 正式妆」强度 |
| L2 | 发型造型 | 发髻/束发/编发 + 发饰 |
| L3 | 中衣/内搭 | 替换白色基础中衣 |
| L4 | 外衣/主服 | 大袖衫/直裾/大氅等 |
| L5 | 配饰 | 头饰/耳饰/项饰/腰饰/手饰 |

## 三、妆容约束（L1）

### 底模到衍生妆造策略（关键）

> 角色底模虽为素颜，但衍生资产默认进入妆造流程。系统应根据用户提供的线索分析妆造需求，并在基础妆、轻妆、正式妆之间决策强度，而不是保持素颜。

### L1 线索分析与妆容决策

| 步骤 | 处理内容 | 决策结果 |
|---|---|---|
| S1 | 提取用户线索：面部状态词、情绪词、强度词 | 形成妆容需求摘要 |
| S2 | 过滤非妆容线索：道具/场景/动作/姿态词不作为上妆依据 | 防止误判 |
| S3 | 匹配妆容风格矩阵并给出强度档 | 基础妆 / 轻妆 / 正式妆 |
| S4 | 生成最终 L1 提示词 | 只输出结论，不输出分析过程 |

### 线索到妆容映射（执行口径）

| 线索类型 | 典型线索 | L1 决策 |
|---|---|---|
| 无明显面部强调线索 | 仅服饰/发型变化，未强调情绪与状态 | 基础妆 |
| 轻微面部线索 | 轻柔、含笑、气色微提 | 轻妆（极淡） |
| 明确病弱线索 | 面色苍白、唇色极淡 | 病弱梨妆（轻妆） |
| 明确正式仪式线索 | 盛装、典礼、华贵亮相 | 正式妆（受控） |

| 风格 | 适用场景 | 核心提示词 |

| 清雅素妆 | 日常、初遇、闺中 | 扁平妆容、淡雅色块、简约化妆 |

## 八、输出：衍生人物需求正文

> 衍生资产以**父角色的多视图**为参考图（参考图1）生成新的多视图。系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（主大头照 + 正面/侧面/背面全身、纯白背景等）。所以你**只写人物本身**：身份锁定 + 新的服化妆造 + 表情 + 画风；不要写排版、背景、视图、比例，也不要出现「四视图」「定妆照」「拼图」等字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 速查表、分层构建方案、视觉约束表、禁止事项表、衍生方案、输出建议、核心要素表、标题、编号、Markdown 符号、代码块、解释说明 |
| 禁止场景 | **不包含场景/环境描述**，不输出任何场景/环境/天气叙事内容（场景属于场景资产范畴） |
| 禁止道具 | **不包含任何道具交互**，不输出伞/剑/扇/书/灯笼/酒杯等手持物或交互物（道具属于道具资产范畴） |
| 禁止姿态变化 | **不改变底模姿态**，不输出行走/回眸/举手/侧身/奔跑等任何动作或体态变化 |
| 禁止画面描述 | 排版/背景/视图/画幅比例/镜头机位 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 |
|---|---|
| 第一段 · 身份锁定与新服化 | 固定以「以参考图1中人物为唯一脸部身份母版，保持骨相五官、发际线、肤色与体型不变，只替换服化妆造：」开头；然后按 L1→L5 写：妆容（先按第三节 S1–S4 决策档位与风格，用色块描述）、发型与发饰（几何扁平形）、中衣/内搭、外衣主服（写到下装与鞋履）、配饰；每件写清纯色色块颜色，不写面料光泽 |
| 第二段 · 脸部身份复述 | 用 2–4 句复述父级描述里的关键脸部特征（脸型轮廓线、眼形色块、眉线、鼻嘴画法、肤色、身高与头身比），强调与参考图1完全一致 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态；结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 2d flat design、vector art、flat illustration、minimalist、clean lines、solid colors、线条清晰、色块分明；按场合给低饱和古风主色调；固定写「无光影、无渐变、无高光，纯平涂色块」 |

## 十、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 第一段必须以「以参考图1中人物为唯一脸部身份母版…只替换服化妆造：」开头；叠加后轮廓必须与底模一致 |
| R2 | 服饰必须用「线条清晰 + 色块分明」，并写到下装与鞋履 |
| R3 | 女性配饰必须「扁平化 + 几何形」 |
| R4 | 妆容/发型/服饰/配饰风格统一 |
| R5 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R6 | 第四段必须包含本风格锚词（2d flat design / vector art / flat illustration / solid colors）与「无光影、无渐变」 |
| R7 | **只输出四段正文**——禁止输出速查表/分层方案/视觉约束/禁止事项/衍生方案/输出建议等任何非正文内容 |
| R8 | **禁止包含场景描述**——人物衍生资产不涉及场景/环境/天气叙事，场景属于独立资产类型 |
| R9 | **禁止道具交互**——不包含任何手持物/交互物（伞/剑/扇/书等），道具属于独立资产类型 |
| R10 | **姿态保持不变**——全身视图保持底模自然站立姿态，禁止任何动作/体态/姿势变化 |
| R11 | **L1 必须先分析再决策**——先解析用户面部线索，再确定基础妆/轻妆/正式妆 |
| R12 | **所有衍生资产均需妆造**——正常情况不保持素颜，至少使用基础妆 |
| R13 | **上妆强度受控**——即使上妆也需克制，不得出现现代扁平浓妆/夸张彩妆效果 |
| R14 | **道具/场景/动作不作强度升级依据**——仅凭道具，环境，动作等信息不得把基础妆抬高为更强妆容 |

| X5 | 输出正文以外的任何内容（表格/方案/建议/解释/变体等） |
| X6 | 在人物衍生资产中加入场景描述（山道/雨景/室内/街道/天气等环境元素） |
