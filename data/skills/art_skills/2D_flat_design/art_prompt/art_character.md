# 人物基础形象（多视图人物需求）生成 · 扁平风约束手册

---

## 一、基础形象原则

1. **轮廓即灵魂** — 线条是角色唯一锚点，扁平色块分层构建
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **多视图为锚** — 一张人物多视图（主大头照 + 正/侧/背全身）同时锁定轮廓、面容、体型、发型和基础服装，是分镜与视频引用的唯一形象
4. **色块表达** — 无阴影渐变，靠色块对比表达层次

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 扁平矢量插画、纯色色块、清晰线条、无渐变无光影 |
| 气质 | 必须从角色描述提炼整体气质关键词，并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 校服 / 学院装 |
| 上班族 | 职业便装（衬衫+裤装/裙装） |
| 居家/休闲 | 休闲常服（T恤+裤装/连衣裙） |
| 运动/活泼 | 运动套装 |
| 特殊职业 | 对应身份服装（医生/警察/教师等） |
| 角色描述未明确 | 简洁日常常服 |

### 着装统一规则

- 服装风格须与扁平矢量插画美学一致（纯色色块、无渐变、无光影）
- 颜色低饱和纯色填充，无复杂花纹/装饰，便于后续衍生叠加
- 服装写到下装与鞋款（款式、颜色），全身三视图要完整展示
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 七、输出：人物需求正文

> 系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（16:9 多视图拼图：主大头照 + 正面/侧面/背面全身、纯白背景、构图比例与一致性要求）。所以你**只写人物本身**，不要写排版、背景、视图、比例、镜头位置，也不要写「四视图」「定妆照」「拼图」之类的字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【人物需求】标签本身 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；手持道具 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 身份与造型 | 名字、年龄、身份、性格气质；所处时代与场合；素颜无妆；发型；服装从上装写到下装和鞋款；每件的纯色色块颜色 | 着装按第六节「着装选择原则」选；颜色写成低饱和纯色（如茶白、竹青、雾蓝），不写面料纹理与光泽；明确写「素颜无妆、无发饰、无配饰、无复杂花纹」 |
| 第二段 · 锁定脸部身份 | 「锁定同一张可复用的{年龄}{性别}脸部身份：」开头，依次写脸型轮廓、额头与刘海、下颌与下巴、眼型与眼色、眉、鼻、嘴、耳朵、肤色、体型身材 | 五官由角色描述推导，用扁平画法写到可复现（如「鹅蛋形脸部轮廓线」「杏仁形深棕色块眼，无瞳孔细节与高光」「鼻子只用一小段折线表示」）；肤色写单一纯色填充；发型写单色色块与轮廓线；体型按第四节写身高与头身比 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态 | 结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 本风格的渲染锚词与质感、主色调、光线处理 | 用本手册的风格锚词：2d flat design、vector art、flat illustration、minimalist、clean lines、solid colors、扁平矢量插画、纯色色块、清晰轮廓线；光线固定写「无光影、无渐变、无高光，纯平涂色块」；避免 3D 渲染与 CG 质感 |

## 八、示例（仅示意写法，内容按角色描述生成）

```
苏晚，22岁，古镇茶馆掌柜的女儿，性格爽利热心、嘴硬心软，做事麻利，眼里总带着几分机灵。古风小镇日常营业时的基础造型：素颜无妆；纯黑色及腰长发自然散落，中分，无发饰；茶白色窄袖交领短衫，竹青色及踝长裙，腰间一条同色细布带，脚穿黑色圆口布鞋；衣物均为纯色色块，无纹理、无复杂花纹、无配饰。

锁定同一张可复用的年轻女性脸部身份：鹅蛋形脸部轮廓线，下颌线干净利落，下巴小而略尖；额头光洁，中分发线清晰；眼睛为略微上挑的杏仁形深棕色块，无瞳孔细节与高光，上眼线用一道稍粗的黑色线条勾出；眉毛是两道细长平直的黑色短线，眉尾微扬；鼻子只用一小段折线表示；嘴是一条带轻微上扬弧度的短线，唇色为浅藕粉单色；耳朵为简化的小半圆轮廓，一半被头发遮住。肤色为暖米色单一纯色填充，无腮红渐变、无高光。发型为纯黑单色色块，外轮廓线流畅，无发丝细节。身高约 165cm，七头半比例，身材修长，肩颈用简洁线条表达。

主大头照选择她招呼熟客时爽快的神情：正面平视，眼形微眯，嘴线轻轻上扬。主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。

2d flat design，vector art，flat illustration，minimalist，clean lines，solid colors，扁平矢量插画，纯色色块分层构建，轮廓线清晰统一；茶白、竹青、墨黑与暖米色为主的低饱和配色，色块对比表达层次；无光影、无渐变、无高光，纯平涂色块；避免 3D 渲染与 CG 质感。
```

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态，并声明「无发饰、无配饰」 |
| R2 | 必须根据角色描述声明合适的常规着装（如学生→校服、上班族→职业便装、居家→休闲常服），并写到下装与鞋款；禁止内衣打底 |
| R3 | 第二段必须逐项锁定脸型轮廓与五官（用扁平画法描述），具体到可复现 |
| R4 | 必须指定角色身高并通过头身比约束全身比例（女性默认160-170cm/7-8头身，男性默认175-185cm/7.5-8.5头身） |
| R5 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R6 | 第四段必须包含本风格锚词（2d flat design / vector art / flat illustration / solid colors）与「无光影、无渐变」 |
| R7 | 只输出四段正文，不输出任何排版、背景、视图说明 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 光影/阴影/渐变/高光效果；面料纹理、发丝细节、毛孔等写实描述 |
| X3 | 3D渲染/CG质感 |
| X4 | 写排版/背景/视图/比例/镜头机位，或出现「四视图」「定妆照」「拼图」「多视图」字样（这些由系统模板负责） |
| X5 | 夸张变形表情、动态姿势、场景环境叙事、手持道具 |
| X6 | 忽略身高和头身比约束，身高必须明确声明并通过头身比换算体现全身比例 |
| X7 | 输出标题、编号、表格、解释等正文以外的内容 |
