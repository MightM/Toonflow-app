# 古风魅惑 · 超写实真人

本风格专为"古风情欲张力 · 江湖与宫闱"题材打造，所有美术提示词、规范和生成内容均限定于：

- **架空古代世界观**：以中国古代为背景（朝代由剧本指定，默认架空），覆盖宫闱、王府、闺阁、青楼、江湖客栈、山寨、军营、战场、刑房牢狱、温泉浴池、洞房、庙宇、市井等一切剧情需要的空间；杜绝现代元素。
- **超写实真人摄影**：所有角色、场景、道具以真人写实电影摄影为标准——毛孔、发丝、绢纱、铠甲、血迹都真实可信，拒绝 3D 渲染与 CG 感。
- **古风魅惑美学**：肚兜、亵衣、薄纱寝衣、湿衣贴身、抹胸襦裙、宽衣解带、堕马髻、红烛罗帐、青楼歌舞、洞房花烛、落红，通过烛光与纱幔的遮与露直接呈现情欲张力；武侠与战争段落的血迹、伤口、厮杀同样如实呈现。
- **人各有貌**：主角、配角、丫鬟、家丁、士兵、老鸨、乞丐在脸型、肤色肤质、体型、年龄感、胡须发式上必须拉开差距，观众一眼能分清谁是谁。
- **性感但非色情**：只守两条底线——未成年角色不性感化，不直接画出生殖器、女性乳头与性交动作；其余按剧情如实呈现。

## 适用范围

- 古风情感、宫斗宅斗、青楼恩客、江湖武侠、战争权谋、强抢民女与英雄救美、洞房与侍寝、复仇与刑讯等题材的 AI 美术生成（角色、场景、道具、分镜、视频）
- 需要高辨识度人物、烛光纱幔的电影级古风光影、强烈情绪与情欲张力的视觉创作

## 允许内容

- 服饰与露肤：肚兜、亵衣亵裤、薄纱寝衣、湿衣贴身透出身形、抹胸襦裙、酥胸半露、露背、开衫半褪、只披一件外袍、赤足、赤裸上身（男）、铠甲下的中衣、破损染血的衣物

## 严禁内容（仅此几条）

- **未成年角色的性感化**：丫鬟、书童、歌姬等一律默认成年；未成年角色可以出现，但不穿暴露服装、不出现在亲密 / 撩人 / 暗示画面中、不与成年人的亲密戏同框
- **直接画出生殖器、女性乳头与性交动作本身**：到这一步用罗帐、床单、手臂、长发、纱幔遮挡，或剪影、烛灭、帐落转场

在本风格下，您将体验到：

- 每个角色有自己的脸、肤色、体型和年龄感：花魁与丫鬟不同貌，将军与士卒不同貌，配角与路人可以有雀斑、疤痕、皱纹、络腮胡、发福、驼背
