# 人物衍生资产（衍生多视图人物需求）生成 · 古风魅惑约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模（父角色多视图，即参考图1）完全一致，禁止面容偏移
2. **身形不变** — 身高、头身比、身材线条与底模一致，服装只负责"展示"身形
3. **姿态不变** — 全身视图保持自然站立，禁止任何姿态/动作/体态变化
4. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
5. **强度跟剧情** — 露肤与性感强度按场合和剧情选档，肚兜、亵衣、薄纱寝衣、湿衣、破损染血的衣物都是合法的衍生状态；只守「不露出乳头与生殖器」这一条
6. **服化 + 状态范畴** — 叠加妆容/发型/服饰/配饰，以及附着在人物身上的状态（湿发湿身、哭花的妆、淤青鞭痕、血迹、绷带、撕破的衣物、绳索勒痕）；不引入手持道具、场景环境、姿态动作
7. **世界观一致** — 所有服化元素为古代形制，无现代元素

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 父角色的多视图（参考图1），脸部身份与体型不修改 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「素净妆 / 桃花妆 / 艳妆 / 残妆」强度 |
| L2 | 发型造型 | 发髻 / 束发 / 编发 / 散发 + 发冠 / 发簪 / 步摇 / 花钿 |
| L3 | 内层 | 肚兜 / 抹胸 / 亵衣亵裤 / 中衣 / 薄纱衬裙 |
| L4 | 主服 / 外衣 / 鞋履 | 襦裙 / 大袖衫 / 褙子 / 长衫 / 劲装 / 铠甲 / 嫁衣 / 寝衣 / 罗袜绣鞋 / 长靴 |

| 步骤 | 处理内容 | 决策结果 |

## 八、输出：衍生人物需求正文

> 衍生资产以**父角色的多视图**为参考图（参考图1）生成新的多视图。系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（主大头照 + 正面/侧面/背面全身、纯白背景等）。所以你**只写人物本身**：身份锁定 + 新的服化妆造 + 表情 + 画风；不要写排版、背景、视图、比例，也不要出现「四视图」「定妆照」「拼图」等字样。

| 项目 | 约束 |
