# 人物基础形象（多视图人物需求）生成 · 古风魅惑约束手册

---

## 一、基础形象原则

1. **人各有貌** — 五官、肤色肤质、体型、年龄感、发式胡须是角色唯一锚点，每个角色都要有自己的一张脸和一副身体，拒绝千人一面
2. **角色分层** — 主角是高质感的美人或俊杰，配角、丫鬟、家丁、士卒、乞丐可以普通、可以有瑕疵；一部剧里不能人人「绝色」
3. **年龄真实** — 年龄由剧本决定并如实体现：十八岁与四十岁不能是同一张脸；未成年角色（子女、幼童、书童）以日常、家庭方式呈现
4. **身形之美** — 主角身材匀称、线条优美是本风格的核心卖点，但线条来自角色本身（纤细、丰腴、健硕、骨感各有其美），不是同一个模板
5. **角色为本** — 基础着装是角色在剧本里的「日常默认态」，由身份、阶层与常驻场景决定；礼服、寝衣、铠甲等特定服化为后续叠加层
6. **多视图为锚** — 一张人物多视图（主大头照 + 正/侧/背全身）同时锁定面容、体型、发型和基础服装，是分镜与视频引用的唯一形象
7. **真人写实** — 以真人写实电影摄影为锚点，毛孔、汗毛、胡茬、血色真实，拒绝 3D 渲染、CG 与磨皮

### 角色分层

| 层级 | 面容标准 | 体型标准 | 写法要点 |
|---|---|---|---|
| 主角（男女主、主要对手） | 高质感、有辨识度的美；允许一个「不完美但迷人」的特征（泪痣、小虎牙、鼻梁微驼、眼下一道浅疤） | 线条优美，但女主之间、男主之间必须不同类型（一个纤细高挑、一个丰腴娇小；一个宽肩武人、一个瘦削书生） | 五个维度全部写具体 |
| 配角（家人、闺中密友、师兄弟、情敌、妃嫔） | 有辨识度即可，可普通、可老、可胖、可有瑕疵 | 与主角明显拉开（身高差 ≥ 8cm，或体型类型不同） | 至少 3 个维度与主角不同 |
| 功能角色（丫鬟、家丁、侍卫、士卒、老鸨、龟公、店小二、山贼、乞丐、太监、嬷嬷） | 普通人长相，鼓励雀斑、麻子、皱纹、胡茬、风霜、油光、缺牙 | 随身份来：侍卫壮实、山贼粗野、书生瘦弱、老鸨发福、乞丐佝偻 | 一句话给出最抓眼的 2 个特征即可，不要写成美人 |
| 未成年角色（子女、幼童、书童、学童） | 孩童或少年的真实长相（婴儿肥、乳牙缝、青春痘都可以） | 与年龄相符的身高与头身比（5–7 头身） | 日常衣着；不写任何性感化描述 |
| 中老年角色（父母、师父、太后、老将、族长） | 皱纹、眼袋、法令纹、松弛、白发白须、老年斑如实写 | 发福 / 消瘦 / 微驼背 | 年龄感必须从面容和体态两处体现 |

### 自检

- 把剧中已有角色的「脸型 + 肤色 + 体型 + 发式胡须 + 标志性特征」列一遍，新角色至少 3 项不同
- 同性别、同年龄段的两个主角，不能同为「瓜子脸 + 冷白皮 + 七头半身 + 乌黑及腰长发」
- 肤色不要全剧清一色「冷白」：闺秀冷白可以，江湖女子、农妇、武人、士卒换成蜜色、小麦或黝黑
- 「绝色」「倾国倾城」「完美面容」不是描述，删掉，换成具体特征

## 八、输出：人物需求正文

> 系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（16:9 多视图拼图：主大头照 + 正面/侧面/背面全身、纯白背景、构图比例与一致性要求）。所以你**只写人物本身**，不要写排版、背景、视图、比例、镜头位置，也不要写「四视图」「定妆照」「拼图」之类的字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【人物需求】标签本身 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；手持道具 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 身份与造型 | 名字、年龄、身份阶层、性格气质；所处朝代与处境；发式（与胡须）；服装从上装写到下装和鞋款；面料材质；配饰 | 着装按第七节「着装选择原则」选；写清颜色与材质；写明「无发冠、无发饰」；明确去除与设定冲突的元素（如「无现代元素」） |
| 第二段 · 锁定脸部身份 | 「锁定同一张可复用的{年龄}{性别}脸部身份：」开头，依次写脸型骨相、额头与发际线、颧骨、下颌与下巴、眼型与瞳色、眼距与眼皮、眉、鼻梁与鼻头、嘴唇与人中、耳朵、肤色肤质、标志性特征、体型身材 | 先按第二节五个维度选定取值再落笔，具体到可复现（例如「眼距约一只眼宽」「下巴短而圆润」「左眼下一颗泪痣」）；肤质写「素颜无妆，保留毛孔与细小汗毛，无磨皮」并写出该角色的肤感差异；体型按第五节写身高、头身比与身材类型 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体情绪，写清眉眼嘴的状态 | 结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 本风格的写实质感锚词、主色调、光线 | 写「真人写实影视人物摄影质感，保留真实皮肤毛孔、虹膜、自然发丝、衣物缝线和面料纹理」；主色取服装的中国传统色；柔和均匀商业影棚布光，清晰高分辨率；避免塑料感、蜡像感、3D 渲染 / CG 感、过度磨皮 |

## 十、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须写明年龄并给出与年龄相符的面容与体态；未成年角色以日常方式呈现 |
| R2 | 必须先按第二节五个维度选定与剧中其他角色不重复的取值，再写第二段 |
| R3 | 第二段必须逐项锁定脸型与五官，具体到可复现，并至少写出 1 个标志性特征 |
| R4 | 必须根据角色身份声明日常古装着装，并写到下装与鞋款；功能角色用服装拉开阶层与身份差；写明「无发冠、无发饰」 |
| R5 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R6 | 第四段必须包含本风格锚词（真人写实影视人物摄影质感 / 真实皮肤毛孔 / 自然发丝 / 面料纹理）与影棚布光 |
| R7 | 只输出四段正文，不输出任何排版、背景、视图说明 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 用「绝色」「倾国倾城」「完美面容」「标准身材」等模板词代替具体特征；同一部剧两个角色五个维度中三项以上相同 |
| X2 | 未成年角色的任何性感化描写（暴露服装、撩人姿态、身体线条描述） |
| X3 | 身材比例畸形（巨乳细腰漫画化、腿长失真）——丰腴、微胖、发福是真实体型，不算畸形；断臂、瞎眼等剧情伤残写明是伤 |
| X4 | 塑料感、蜡像感、3D 渲染 / CG 感、过度磨皮、现代元素 |
| X5 | 写排版/背景/视图/比例/镜头机位，或出现「四视图」「定妆照」「拼图」「多视图」字样（这些由系统模板负责） |
