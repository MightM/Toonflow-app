## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「真人写实摄影」风格锚定词（real photography / photorealistic / RAW photo），禁止 3D 渲染与 CG 词 |
| R2 | 必须声明「电影级烛光或自然光 + 强对比 + 极致细节」 |
| R3 | 面部必须使用「面容细腻渲染 + 皮肤细腻」，并写出**这个角色自己的**辨识特征；不要用「完美面容」「绝色」把所有人写成同一张脸 |
| R4 | 皮肤必须保留毛孔、汗毛与自然血色，禁止磨皮与蜡像感；允许并鼓励雀斑、痣、细纹、胡茬、疤痕、晒痕、鞭痕、淤青等真实肤感差异 |
| R5 | 发丝必须使用「根根分明 + 发丝细腻渲染」，胡须同样根根分明 |
| R6 | 纹理必须声明「材质纹理超清晰」（绢纱 / 云锦 / 棉麻 / 皮革 / 铁甲 / 玉石 / 木器 / 血迹） |
| R7 | 含人物的提示词必须写明年龄段与年龄感：成年角色写「{年龄}岁{女子/男子}」并给出与年龄相符的面容体态（十八岁与四十岁不能是同一张脸）；未成年角色写「{年龄}岁{女童/男童/少年/少女}」，以日常、家庭、学堂方式呈现 |
| R8 | **角色差异化**：同一部剧里每个角色至少有 3 个一眼可辨的外貌锚点（脸型骨相 / 肤色肤质 / 体型身高 / 发式胡须 / 标志性特征），主角、配角、丫鬟、家丁、士卒不得共用同一套「绝色美人 + 标准身材」模板；多人同框时逐一写清各自的区分点 |
| R9 | 情绪必须外化成身体语言、表情、姿势与光线，可以直接写撩人姿势、暗示动作、宽衣解带、贴身接触、恐惧与挣扎、厮杀与血迹；不要为了「含蓄」把戏剧动作换成空镜或转场 |
| R10 | 所有服化道、建筑、器物必须符合古代世界观，无现代元素 |
