# 分镜表古风魅惑约束 · 超写实真人 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供古风魅惑风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **同场戏光影统一** — 一场戏内不应出现两种以上光影方案（A-H），除非有明确叙事转折（如烛火被吹灭 → 月色、门被踹开火把涌入、夜 → 晨光）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景，镜头组内保持主色+辅色连续
- **光源角度规范** — 人物主光默认 45° 侧前方烛光或窗光低调光，必须写明轮廓光位置（纱幔透光 / 月色勾勒发丝肩线腰线）
- **暖光跟随亲密度** — 两人距离越近，烛光越集中在肌肤与面部；分开或冲突时暖光退场，转冷或转单一火光
- **光影转场是高级手段** — 红烛燃尽、纱帐落下、窗纱透进晨光、火把被扑灭，可在分镜表中标注光影变化点

---

## 三、张力镜头节奏

- **视线停留** — 关键对视镜头时长 ≥ 3 秒，给观众遐想时间；对视常用过肩镜头 + 反打特写，纱幔或屏风可作前景遮挡
- **局部特写组合** — 每场张力戏至少安排 1 组局部特写：锁骨与璎珞、指尖划过杯沿、红唇、喉结滚动、绣鞋落地、罗袜脚踝、衣带被解开、肩带滑落、肚兜系带、腰臀曲线、湿发贴颈、水珠沿锁骨滑落
- **先局部后整体** — 人物登场优先"绣鞋落步 → 裙摆 / 腿部线条 → 腰臀 → 回眸面部"的由下至上揭示；纱后人影 → 纱幔掀开 → 面容也是本风格的经典登场
- **慢节奏动作** — 亲密段落人物动作默认放慢：转身、抚发、倚靠、抬眼、解衣带都标注"缓慢"或"慵懒"；胁迫、打斗、救援、战场段落改为急促，标注"猛地""一把""一剑"
- **情绪顶点拍出来** — 深吻、抱上床榻、宽衣、解肚兜系带、抚摸、撕扯、掐颈、破门、剑穿胸都要有正面镜头；只有到生殖器、乳头、性交动作本身这一步才用转场留白（帐落、烛灭、镜头移向窗外月色）
- **胁迫戏三段式** — 「威胁逼近（施暴者进入画面，受害者后退 / 被抵住柱子）→ 失控（拖拽、按倒、点穴、撕扯、恐惧特写、挣扎）→ 转折（救援者破门 / 反击 / 屈服的绝望）」，每段至少 2 个镜头，受害者的恐惧与反抗要有面部特写
- **救援戏节奏** — 破门或出剑的镜头用短镜头快切，接一个把人拉进怀里或护在身后的长镜头，再接一个受害者情绪释放的特写
- **武打与战场节奏** — 起手慢（对峙、按剑、呼吸）→ 交手快（快切、甩镜、剑光）→ 收势慢（吐血、倒地、血滴、升格）；战场用全景尸横遍野 + 中景厮杀 + 特写血溅铠甲的三级组合
- **多人镜头点名区分** — 同框两人以上时，分镜描述里给每个人一个可辨特征（麻花辫小丫鬟、络腮胡瞎眼的山贼、穿肚兜的女主），避免生成时脸重合

## 四、环境动态

- **环境动态增加呼吸感** — 每 3-4 个镜头至少一个环境动态：烛火摇曳、纱幔拂动、香炉青烟、酒液倾倒、水汽升腾、花瓣落在水面、飞雪、烽火烟尘、乌鸦惊起、旗帜猎猎、雨打窗纸
- **古风元素优先** — 环境动态必须来自古代世界观，禁止现代元素

---

## 五、尺度与张力表达

- **两条底线**：未成年角色不性感化（丫鬟、书童、歌姬默认成年；子女、幼童只出现在日常、家庭、学堂镜头，穿日常童装，不与亲密戏同框）；不直接呈现生殖器、女性乳头与性交动作本身
- **其余照写**：肚兜、亵衣、薄纱寝衣、湿衣贴身、破损染血的衣物、囚衣；撩人姿势、暗示动作、坐上大腿、抵柱、深吻、抱上床榻、宽衣解带、褪肩带、解肚兜系带、罗帐内相拥、隔衣或贴肤抚摸、沐浴、侍寝、洞房、床单上的落红；强抢、绑缚、下药、点穴、刑讯、鞭打、掐颈、撕扯、恐惧、挣扎；决斗、刺杀、吐血、断臂、尸体、血迹
- **局部特写不设禁区**：胸部曲线、臀腿、大腿根、腰腹都可以作为特写焦点，只要关键部位被衣物、床单、长发或身体遮挡
- **拥吻与床戏镜头拆法**：「近景起势（额头相抵 / 抵柱）→ 局部特写（手贴腰际 / 解衣带 / 肩带滑落 / 肚兜系带）→ 全身或半身（抱上床榻 / 相拥倒向床褥）→ 局部与剪影（罗帐上的轮廓、交缠的手、散落的衣物）→ 转场（帐落 / 烛灭 / 窗外月色）→ 晨起（凌乱床褥、落红、只披外袍）」，转场只放在中间那一步
- **胁迫戏拍受害者视角**：恐惧、反抗、求救的面部特写与施暴者的压迫感并重，让观众揪心；不把胁迫过程拍成施暴者的炫耀
- **战争与刑讯**：血迹、伤口、尸体如实拍，用于表现惨烈与残酷；不做无剧情目的的内脏特写

## 六、运镜与转场规范

- **亲密段落慢** — 缓推、缓拉、环绕、低角度跟随、焦点转移（前景烛火 / 纱幔 → 后景人物）、升格
- **胁迫、武打、战场段落快** — 急推、手持晃动、甩镜、快切、升格收势都可以用，节奏跟着恐惧和暴力走
- **机位不设禁区** — 低角度仰拍裙摆与赤足、俯拍乳沟与锁骨、窥视视角（纱幔缝隙、屏风后、门缝、窗纸破洞、树后）都可以用，只要服务于撩拨、悬念或威胁感
- **禁用花式转场** — 划屏、旋转、百叶窗特效转场等与本风格不兼容；用纱幔落下、烛火熄灭、空镜衔接
- **仪态** — 古风人物举止符合时代：不出现耸肩、摊手等现代肢体语言；但泼辣、粗野、癫狂的角色可以打破端庄
