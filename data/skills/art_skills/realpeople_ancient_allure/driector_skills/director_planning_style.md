# 古风魅惑约束 · 超写实真人 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以墨玉黑（C2）、青黛（C5）为暗部基底，烛光暖肤（C1）、鎏金（C4）、琥珀暖（C8）落在人物与高光处，朱砂红（C3）落在唇、肚兜、红烛、嫁衣与血迹上，形成「暗底 + 烛光暖肤 + 朱红点睛」的魅惑基调
- **冷暖叙事对比** — 烛光越靠近人物肌肤，情欲张力越强；冲突、疏离、囚禁段落降低暖光占比，转向青黛月色与单一火把
- **胭脂绛紫只做点缀** — 青楼灯纱、夜宴、梦境段落的染色，面积不超过画面 25%
- **色盘先行原则** — 段落规划先绑定情绪场景（初见惊艳 / 暧昧试探 / 青楼夜宴 / 洞房花烛 / 温泉沐浴 / 胁迫囚禁 / 战场厮杀 / 月下决斗 / 晨起余温），再确定主色+辅色与光影方案
- **禁用色域** — 荧光霓虹、平均无暗部的"白开水"照明、日韩小清新滤镜、现代色彩语言

## 二、光影方案体系

- **光影即欲望** — 8 套光影方案对应不同情绪段落，导演规划阶段在段落层面确定光影基调方向，而非逐镜指定
- **光源角度** — 人物主光默认 45° 侧前方烛光或窗光低调光，保留面部与身体一侧暗部；轮廓光从纱幔或月色后侧勾勒发丝、肩线、腰线

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 红烛罗帐 | 朱砂红帐透光 + 双烛暖光 + 大面积暗部 | 洞房、侍寝、幽会 |
| B | 灯纱染色 | 绛紫 / 胭脂灯纱 + 鎏金烛焰 + 香炉青烟 | 青楼、夜宴、献舞 |
| C | 窗纱侧光 | 月白窗纱漫射 + 条纹木格光影 | 闺中日间、更衣、试探 |
| D | 月光冷辉 | 青黛月色顶侧光 + 剑刃反光 + 硬影 | 夜行、决斗、刺杀、思念 |
| E | 水汽焦散 | 烛光穿过水汽，水面焦散映在肌肤 | 温泉、沐浴、雨中 |
| F | 单一火光 | 火把 / 油灯单点光，人物半张脸在黑里 | 牢狱、刑讯、囚禁、山寨 |
| G | 烽火战场 | 阴天漫射冷光 + 烽火暖点 + 烟尘 | 战场、城破、劫后 |
| H | 晨光纱帐 | 月白纱帐逆光、低对比 | 晨起余温、事后、和解 |

- **补充方案** — 大婚可用满堂红烛高光（明亮但保留缎面反光）；家庭日常可用庭院天光中等对比
- **氛围方向映射** — 每场戏氛围方向应映射到上述 A-H 某一方向，确保视觉一致性

## 三、质感方向

- **超写实真人摄影** — 毛孔可见、汗毛与胡茬根根分明、绢纱半透、铠甲划痕、血迹干湿有别；不是 3D、不是 CG、不是磨皮
- **肌肤是主角** — 锁骨、肩头、颈线、腰腹、大腿的烛光高光与暗部过渡是画面焦点，湿发贴颈与水珠是加分项
- **材质高光** — 缎面流光、薄纱透光、铠甲甲片反光、玉器温润、酒液高光、血迹的湿润反光，每场戏至少一种
- **氛围层** — 香炉青烟、浴池水汽、烽火烟尘、飞雪、落花让画面"有空气"，但不能糊掉主体
- **性感要拍出来** — 撩人姿势、暗示动作、宽衣解带、肚兜、侍寝、罗帐内相拥都直接进画面；遮挡、剪影、转场只用在最后一步（生殖器、乳头、性交动作本身）
- **人各有貌** — 规划阶段就为主角、配角、丫鬟、家丁、士卒分配不同的脸型、肤色、体型、发式胡须与标志性特征，写进人物小传；观众靠外貌就能分清谁是谁

## 四、古风魅惑空间元素

- **纱幔 / 屏风 / 罗帐** — 遮与露的天然道具：纱后的人影、帐内的轮廓、屏风后的更衣，是本风格最核心的构图语言
- **青楼花厅 / 雅间 / 后院** — 迎客、献舞、恩客与花魁的拉扯；灯纱、屏风、酒案、琵琶是标配
- **寝殿 / 洞房 / 浴池** — 私密段落的容器：红烛、床褥、水汽、褪下的衣物
- **长廊 / 密室 / 马车内 / 轿中** — 封闭或纵深空间放大两人距离的变化，是张力戏的首选容器
- **牢狱 / 刑房 / 山寨 / 荒郊官道** — 胁迫、囚禁、劫掠的空间：铁链、火盆、绳索、翻倒的马车
- **战场 / 城墙 / 军营** — 厮杀与血的空间：断旗、尸体、烽火、舆图
- **家庭与日常空间** — 厅堂、学堂、厨房、庭院：用天光和生活道具区分于夜色段落，是子女、父母戏的容器
- **转折点用视觉而非解释** — 视线交汇、手指停在衣带上、绣鞋停步、肚兜系带被解开、门被踹开、剑出鞘，都是转折信号

## 五、尺度与张力表达（全片）

- **只有两条底线**：① 未成年角色不性感化——丫鬟、书童、歌姬一律默认成年；子女、幼童可以出场，但只在日常、家庭、学堂段落，不进入亲密与暗示画面；② 不直接呈现生殖器、女性乳头与性交动作——到这一步用罗帐、床单、手臂、长发遮挡，或剪影、烛灭、帐落、窗外月色
- **亲密段落直接规划**：对视、耳语、坐上大腿、抵柱、深吻、抱上床榻、宽衣解带、褪下肩带、解肚兜系带、罗帐内相拥、隔衣或贴肤抚摸、沐浴、侍寝、洞房、清晨落红都可以写进段落大纲，不必用留白代替
- **胁迫与救援段落直接规划**：强抢民女、山贼掳人、逼婚、下药、点穴制住、绑缚、囚禁、刑讯、鞭打、撕扯衣物、恐惧与挣扎、破门救人、拔剑相向、血溅当场都可以写；受害者的恐惧与反抗是张力来源，救援者的破门是情绪释放点，两者都要给足镜头
- **武侠与战争段落直接规划**：决斗、刺杀、吐血、剑穿胸、断臂、尸横遍野、血染铠甲、屠城、复仇，血迹与伤口如实呈现
- **服装不设限**：肚兜、亵衣、薄纱寝衣、湿衣、破损染血的衣物、囚衣按剧情写进段落说明
- **情绪要调动得起来**：规划时明确每个段落要让观众产生的反应（心跳、脸红、揪心、解气、心疼、热血），并说明用什么画面达成，不写「暧昧」「张力」这类空词

## 六、古风乐器与环境音

### 乐器选择

- **琵琶** — 青楼、夜宴、献舞的核心乐器，急促轮指也用于紧张追逐
- **箫 / 埙** — 孤寂、思念、月下、囚禁段落
- **古琴** — 开场定调、书房幽会、平稳段落
- **二胡** — 悲痛、离别、受创后的哭腔
- **鼓 / 战鼓** — 战场、决斗、破门救人、冲突升级
- **唢呐** — 大婚、命运转折，慎用但一用即核弹
- **低频弦乐铺底** — 危险逼近、欲望压抑、悬念

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 开场 / 夜色建立 | 古琴 + 环境声 |
| 暧昧试探 | 箫 + 低频弦乐 |
| 青楼夜宴 / 献舞 | 琵琶主导 + 鼓点 |
| 洞房 / 侍寝 | 古琴慢板 或 无乐只留烛火与呼吸 |
| 胁迫 / 危险逼近 | 低频弦乐 + 埙 + 金属打击 |
| 救援 / 决斗 / 战场 | 战鼓 + 琵琶轮指 + 弦乐 |
| 受创 / 离别 | 二胡 + 箫 |
| 大婚 / 命运转折 | 唢呐 + 鼓 |
| 晨起余温 / 和解 | 古琴独奏 或 箫独奏 |
| 家庭 / 亲子 | 古筝 + 轻打击乐 |

### 古风环境音

- **典型环境音层次** — 红烛爆芯 / 纱幔拂动 / 绣鞋踩过木廊 / 衣带解开的绸缎声 / 酒液倒入 / 琵琶余音 / 香炉青烟 / 浴池水声 / 铁链拖地 / 鞭子破空 / 铠甲碰响 / 战马嘶鸣 / 兵刃相击 / 乌鸦 / 夜雨滴檐 / 更鼓
- **每场戏标注 1-2 个核心环境音**，其中至少一个是「贴近人物的细节音」（呼吸、绸缎摩擦、鞋跟、烛火、心跳），增强私密感或压迫感
