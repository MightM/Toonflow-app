# 黏土定格动画角色基础形象（多视图人物需求）生成 · 约束手册

---

## 一、基础形象原则

1. **黏土肌理为魂** — 表面可见手工捏塑痕迹，手指压痕/黏土纹理清晰可辨
2. **3D卡通底模** — 基础打底为简化造型的黏土角色，后续服化均为叠加层
3. **多视图为锚** — 一张人物多视图（主大头照 + 正/侧/背全身）同时锁定面容、体型、发型和基础服装，是分镜与视频引用的唯一形象
4. **治愈氛围** — 无妆状态仍需体现角色性格（柔和/圆润/亲切）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型；整体保持黏土圆润感（无尖锐棱角） |
| 风格底色 | 黏土定格动画、3D 卡通渲染、哑光黏土质感、暖调光影 |
| 气质 | 必须从角色描述提炼整体气质关键词（如温暖治愈/稳重可靠/活泼亲切），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装为简化造型，无复杂细节。

### 女性基础服装

简化连衣裙或上衣+裙装，颜色为低饱和暖色调，无花纹装饰。

### 男性基础服装

简化衬衫+裤装，颜色为低饱和暖色调，无花纹装饰。

### 着装统一规则

- 服装风格统一，确保后续服饰叠加无色彩干扰
- 除面部/手部/颈部外基本覆盖
- 服装写到下装与鞋款（款式、颜色、材质，如：连衣裙 + 圆头黏土小皮鞋；衬衫 + 长裤 + 系带短靴），全身三视图要完整展示
- 基础服装仅为安全打底，焦点在面容与体态

## 七、输出：人物需求正文

> 系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（16:9 多视图拼图：主大头照 + 正面/侧面/背面全身、纯白背景、构图比例与一致性要求）。所以你**只写人物本身**，不要写排版、背景、视图、比例、镜头位置，也不要写「四视图」「定妆照」「拼图」之类的字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【人物需求】标签本身 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；手持道具；动态姿势 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 身份与造型 | 名字、年龄、身份、性格气质；所处时代与场合；黏土发型；基础服装从上衣写到下装和鞋款；黏土材质的服装质感 | 服装按第六节：女性简化连衣裙或上衣+裙装、男性简化衬衫+裤装，低饱和暖色调、无花纹；明确写「无复杂发饰、无现代配饰」 |
| 第二段 · 锁定脸部身份 | 「锁定同一张可复用的{年龄}{性别}黏土脸部身份：」开头，依次写脸型、额头、脸颊、下巴、眼型与眼珠、眼距、眉、鼻、嘴、耳朵、黏土肤色与表面肌理、体型身材 | 五官由角色描述推导，保持黏土圆润感、无尖锐棱角，写成可复现的捏塑特征（如「豆豆眼、黑亮眼珠带一点高光」「鼻子是一颗圆鼓的小黏土球」）；肤色按第三节写暖奶油色/暖米色哑光黏土，可见手指压痕；体型按第四节写身高与头身比 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态 | 结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 本风格的渲染锚词与质感、主色调、光线 | 用本手册的风格锚词：黏土定格动画、定格动画风格、3D卡通渲染、哑光黏土质感 matte clay texture、黏土肌理清晰、手工捏塑痕迹；低饱和暖色调；暖调柔光、无硬阴影；避免真人写实质感、光滑塑料感、冷硬光线 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「哑光黏土质感」状态，第二段写明黏土肤色与捏塑肌理 |
| R2 | 必须声明基础服装（女性：简化连衣裙；男性：简化衬衫+裤装），并写到下装与鞋款 |
| R3 | 第一段必须声明「无复杂发饰、无现代配饰」 |
| R4 | 第二段必须逐项锁定脸型与五官，保持黏土圆润感并具体到可复现 |
| R5 | 必须指定角色身高并通过头身比约束全身比例（默认6-7头身） |
| R6 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R7 | 第四段必须包含本风格锚词（黏土定格动画 / 哑光黏土质感 / 手工捏塑痕迹）与暖调柔光 |
| R8 | 只输出四段正文，不输出任何排版、背景、视图说明 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 真人写实摄影质感/照片级真实 |
| X2 | 冷硬光线/硬阴影/高对比 |
| X3 | 尖锐棱角/攻击性姿态 |
| X4 | 写排版/背景/视图/比例/镜头机位，或出现「四视图」「定妆照」「拼图」「多视图」字样（这些由系统模板负责） |
| X5 | 夸张表情、动态姿势、场景环境叙事、手持道具 |
| X6 | 忽略身高和头身比约束 |
| X7 | 输出标题、编号、表格、解释等正文以外的内容 |
