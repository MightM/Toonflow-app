# 黏土定格动画角色衍生资产（衍生多视图人物需求）生成 · 约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模（父角色多视图，即参考图1）完全一致
2. **姿态不变** — 全身视图保持自然站立，禁止任何姿态/动作变化
3. **逐层可控** — 每层独立描述，便于按层替换
4. **风格统一** — 所有服化元素服从同一黏土美学体系
5. **质感不降** — 叠加后黏土质感标准不低于底模
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰，禁止引入道具、场景、环境

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 父角色的多视图（参考图1），脸部身份与体型不修改 |
| L1 | 妆容 | 基础装饰性色彩点缀 |
| L2 | 发型造型 | 发髻/束发+简单发饰 |
| L3 | 中衣/内搭 | 替换白色基础中衣 |
| L4 | 外衣/主服 | 外套/长袍/外衣 |
| L5 | 配饰 | 头饰/耳饰/项饰/腰饰 |

> **范畴边界**：人物衍生资产仅包含 L0–L5 层级（服化妆造），不包含道具、场景环境、姿态动作。

## 八、输出：衍生人物需求正文

> 衍生资产以**父角色的多视图**为参考图（参考图1）生成新的多视图。系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（主大头照 + 正面/侧面/背面全身、纯白背景等）。所以你**只写人物本身**：身份锁定 + 新的服化妆造 + 表情 + 画风；不要写排版、背景、视图、比例，也不要出现「四视图」「定妆照」「拼图」等字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、速查表、分层方案、Markdown 符号、代码块、解释说明 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；道具交互（手持物）；姿态动作 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 |
|---|---|
| 第一段 · 身份锁定与新服化 | 固定以「以参考图1中人物为唯一脸部身份母版，保持骨相五官、发际线、肤色与体型不变，只替换服化妆造：」开头；然后按 L1→L5 写：妆容（先按第三节决策基础/轻/正式装饰妆及风格，哑光黏土质感）、发型与发饰（第四节，保持黏土塑形感）、中衣内搭与外衣主服（第五节，写到下装和鞋履）、配饰（第六节）；写清颜色与黏土材质，服饰写「衣服纹理清晰」 |
| 第二段 · 脸部身份复述 | 用 2–4 句复述父级描述里的关键黏土脸部特征（脸型、眼型与眼珠、鼻嘴、黏土肤色与捏塑肌理、身高与头身比），强调与参考图1完全一致 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态；结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 黏土定格动画、定格动画风格、3D卡通渲染、哑光黏土质感 matte clay texture、黏土肌理细腻渲染、手工捏塑痕迹；按场合给低饱和暖色主色调；暖调柔光、无硬阴影；避免高光/油光/金属镜面反射与真人写实质感 |
