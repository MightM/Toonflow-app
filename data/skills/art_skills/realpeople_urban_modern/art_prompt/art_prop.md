# 道具图像生成 · 都市写实约束手册

---

## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于功能
2. **质感极致** — 材质纹理必须清晰可辨（金属/玻璃/塑料/皮革/布料）
3. **年代一致** — 所有道具必须符合现代都市世界观，禁止古代元素
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 四、三视图说明（由系统负责）

> 系统会把你的输出放进「【道具需求】」一节，再自动追加固定的【输出格式】：同一件物品的 0°、+120°、−120° 三个视图，浅灰中性影棚背景、固定机位与布光。
> 所以你**只写物品本身**：不写版式、视图角度、背景、布光、镜头，也不要写「三视图」「四宫格」「正面图 / 侧面图」之类的字样。

| 编号 | 严禁 |

## 七、输出：道具需求正文

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【道具需求】标签本身 |
| 禁止内容 | 版式 / 视图角度 / 背景 / 布光 / 镜头；人物、手部、持握或佩戴状态 |
| 篇幅 | 全文约 300–600 字 |

### 四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 定位 | 道具名称与在剧情中的作用（为什么重要、与谁相关）；所属世界观与本风格的画面质感定位；与世界观冲突的排除项 | 一两句说清剧情作用，帮助模型判断精致程度与年代感 |
| 第二段 · 锁定形体与结构 | 整体形态与真实尺寸（厘米，或相对成人手掌 / 前臂的比例）；各组成部件、数量与连接方式；开合、机关、卷绕方向等结构状态 | 部件与数量写死，三个角度靠它对齐 |
| 第三段 · 材质、颜色与痕迹 | 主材质与辅材质、颜色（具体色名）、纹样及其走向、光泽；使用痕迹的位置与程度，以及明确不得出现的破损或污渍 | 痕迹写清位置（「边缘」「卷端」），不要泛写「做旧」 |
| 第四段 · 画风与排除 | 本风格的画风质感锚词（取自「风格词参考」）；以「无Logo、无文字、无标签、无多余包装、无人手」结尾，并补上与世界观冲突的排除项 | — |

### 示例（仅示意写法；画风锚词与世界观按本手册与剧情来写）

```
金针腕弩，肖青璇藏在腕甲中的细小金针弩，误伤林晚荣后成为两人关系转折的证据；架空华朝江南古装武侠轻喜剧，写实影视质感，无现代元素与夸张卡通感。

锁定形体与结构：可隐蔽佩戴的精巧袖珍腕弩，整体长度约成人前臂的三分之二，窄而扁平，贴合固定在腕甲内侧。结构包括贴腕弧形底板、可折叠短弩臂、微型弓弦槽、针匣、隐蔽推送滑轨、近距击发扣、保险卡榫及两枚腕甲固定扣环；针匣内整齐收纳六枚极细金针。

主体为温润暗金色铜金合金，边缘略深的氧化铜褐色，局部有细密拉丝、铆钉与转轴；针尖冷亮，机关缝隙与金属接缝清晰可信；只在击发扣与滑轨边缘有轻微使用磨损，无锈蚀、无断裂。

写实影视级道具质感，真实金属拉丝纹理与克制的反光；无Logo、无文字、无标签、无多余包装、无人手，无装饰性现代零件。
```
