# 道具衍生状态生成 · 约束手册（真人都市版）

---

## 一、衍生原则

1. **造型锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异必须一目了然，观众能立即区分
3. **叙事服务** — 每种状态变体服务于特定剧情节点
4. **渐进退化** — 损伤/老化状态应有合理的物理逻辑

---

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 完好无损、光泽如新 | 所有道具 | 崭新、完好无损、光泽如新 |
| 日常使用 | 微磨损、自然痕迹 | 电子产品/生活用品 | 日常使用痕迹、自然磨损 |
| 陈旧 | 明显使用痕迹、老化 | 皮革制品/织物 | 使用痕迹、自然老化 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 小划痕/小裂纹 | 手机/笔记本 | 细微划痕、轻微裂纹 |
| 破损 | 明显裂缝/断裂 | 电子产品/玻璃品 | 裂缝明显、碎裂 |
| 残片 | 仅剩部分/碎片 | 玻璃/陶瓷品 | 残片、碎片 |

### 2.3 特殊状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 污渍 | 污渍附着 | 所有道具 | 污渍、脏污 |
| 水渍 | 水渍、湿润反光 | 纸品/织物 | 水渍、湿润痕迹 |
| 划痕 | 明显划痕 | 金属/玻璃 | 明显划痕、刮痕 |
| 磨损 | 表面磨损 | 皮革/织物 | 磨损痕迹、老化 |
| 破损屏幕 | 屏幕碎裂 | 电子产品 | 屏幕碎裂、裂痕 |

## 三、材质状态变化规则

| 材质 | 崭新 → 日常 | 日常 → 陈旧 | 损伤表现 |
|---|---|---|---|
| 金属 | 亮光泽 → 微划痕 | 划痕 → 氧化斑点 | 凹陷/弯曲/断裂 |
| 玻璃 | 透明 → 微划痕 | 划痕 → 明显裂纹 | 碎裂/缺口 |
| 塑料 | 新光泽 → 微磨损 | 磨损 → 褪色 | 裂纹/变形 |
| 皮革 | 光滑 → 微皱 | 皱折 → 裂纹 | 撕裂/磨损 |
| 织物 | 崭新 → 微皱 | 皱折 → 褪色 | 撕裂/污渍 |

```

基于{道具名}设定图，真人写实摄影风格，自然光线，极致细节，

当前状态：{状态名}，{状态视觉描述}，

纯净中性灰背景，均匀柔光，无硬阴影，
```

## 五、风格约束

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合物理逻辑 |
| R4 | 必须指定「纯净中性灰背景」，均匀柔光，无硬阴影 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤（如金属生锈） |
| X3 | 过度损坏导致无法识别 |

## 六、输出：道具状态需求正文

> 系统会把你的输出放进「【道具需求】」一节，并以父道具当前图（通常是三视图）为参考图1，开头写明「保持物品本体不变」，末尾追加固定的三视图【输出格式】。所以你**只写这个状态与参考图的差异和变化后的样子**，不写版式、视图、背景。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出三段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【道具需求】标签本身 |
| 禁止内容 | 版式 / 视图角度 / 背景 / 布光；人物、手部、持握或佩戴状态 |
| 篇幅 | 全文约 200–400 字 |

### 三段结构

| 段落 | 写什么 |
|---|---|
| 第一段 · 状态变化 | 以「与参考图相比只改变：」开头，写清状态变化（打开、碎裂、点燃、染血…）的部位、程度与形态 |
| 第二段 · 保持不变 | 以「保持不变：」开头，列出外形比例、尺寸、部件与数量、颜色、纹样、原有痕迹 |
| 第三段 · 材质变化与画风 | 状态变化带来的材质表面变化（裂纹走向、焦黑边缘、液体反光…）；本风格的画风锚词；以「无人手、无文字」结尾 |

### 输出约束

| 编号 | 规则 |
|---|---|
| O1 | 只输出三段正文，不输出版式、视图、背景说明 |
| O2 | 状态变化必须写清部位与程度，三个角度都能对上 |
| O3 | 未提到要变的部分一律写进「保持不变」 |
| O4 | 不出现人物、人手、持握或佩戴状态 |
| O5 | 不出现「三视图」「四宫格」「正面图」「侧面图」等版式字样 |
