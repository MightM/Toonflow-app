# 3D国风赛博场景衍生资产生成 · 约束手册
（古风场景+现代都市场景 双向全适配）

---

## 一、衍生原则

（核心约束：古风/都市双场景通用，所有变体严格遵循「风格融合统一、空间逻辑一致」）

1. **空间一致** — 建筑结构/布局/材质、国风赛博核心融合元素在所有变体中保持完全一致
    - 古风场景：固定古建制式/飞檐斗拱/榫卯结构/院落布局/传统纹样的赛博改造逻辑
    - 都市场景：固定楼宇结构/街巷路网/城市功能区布局/国风改造元素（中式飞檐/斗拱/纹样）的融合逻辑
    - 严禁变体间出现元素错位、结构改动、风格割裂
2. **景别驱动** — 同一场景通过不同景别展示不同叙事功能，精准适配古风/都市场景的空间叙事逻辑
3. **时段切换** — 同一空间在不同时间段呈现不同光影氛围，同步适配双场景专属光源的亮度、色温与开关逻辑
    - 古风场景：传统灯笼/符文灯/全息国风投影/霓虹管线
    - 都市场景：楼宇大屏/路灯/车灯/国风霓虹招牌/全息水墨广告
4. **天候变化** — 同一空间在不同天气下呈现不同情绪，同步适配双场景材质与元素的物理反馈
    - 古风场景：雨雾霓虹丁达尔、积雪覆盖飞檐、瓦当滴水、木构湿润肌理
    - 都市场景：玻璃幕墙雨痕反光、路面积水霓虹倒影、飞雪覆盖楼宇飞檐、金属结构霜花
5. **3D为锚** — 所有变体必须保持3D渲染质感，拒绝平面贴图/CG动画感/二次元平涂风格；严格保留PBR物理材质、光线追踪全局光照、体积光、环境光遮蔽、景深虚化，强化双场景专属材质质感
    - 古风专属：风化木构、做旧金属、砖瓦肌理、织物垂褶、漆面磨损、青苔风化
    - 都市专属：超白玻璃幕墙、阳极氧化铝材、清水混凝土、沥青路面、磨砂金属、LED自发光屏

## 六、输出：场景变体需求正文

> 系统会把你的输出放进「【场景需求】」一节，并以父场景当前图（通常是三视图）为参考图1，开头写明「保持场景本体不变」，末尾追加固定的三视图【输出格式】。所以你**只写这个变体与参考图的差异和变化后的样子**，不写版式、视图、镜头。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出三段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【场景需求】标签本身 |
| 禁止内容 | 版式 / 视图 / 镜头焦段 / 画面比例；任何人物、人影 |
| 篇幅 | 全文约 250–500 字 |

### 三段结构

| 段落 | 写什么 |
|---|---|
| 第一段 · 变化 | 以「与参考图相比只改变：」开头，写清时段、天气、灯光方案、陈设增减或损毁程度的具体变化，以及变化出现在哪些位置 |
| 第二段 · 保持不变 | 以「保持不变：」开头，列出空间结构、出入口、主要陈设与道具的位置和数量、核心区域 |
| 第三段 · 变化后的光色与画风 | 变化后主光方向、2–3 个主色、材质表面随之出现的变化（湿润、积雪、焦痕、灰尘…）、可见氛围；本风格的画风锚词；以「无人物、无文字」结尾 |

### 输出约束

| 编号 | 规则 |
|---|---|
| O1 | 只输出三段正文，不输出版式、视图、镜头说明 |
| O2 | 未提到要变的维度一律写进「保持不变」 |
| O3 | 灯光或时段变化必须同步写出新的主光方向与主色 |
| O4 | 场景中不出现任何人物、人影、人体轮廓 |
| O5 | 不出现「三视图」「拼图」「单画面」「俯视」「近景」等取景字样 |
