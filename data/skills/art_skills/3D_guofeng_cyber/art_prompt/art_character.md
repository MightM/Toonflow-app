# 3D超精致建模 通用角色多视图人物需求标准手册

> 一张人物多视图（主大头照 + 正/侧/背全身）同时锁定面容、体型、发型和基础服装，是分镜与视频引用的唯一形象。系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（16:9 多视图拼图、纯白背景、构图比例与一致性要求）。所以你**只写人物本身**，不要写排版、背景、视图、比例、镜头位置，也不要写「四视图」「定妆照」「拼图」之类的字样。

---

## 一、输出格式

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行；全文约 450–750 字 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【人物需求】标签本身 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；手持道具；动态姿势 |

## 二、四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 身份与造型 | 年龄（数字）、性别、详细身份、10 字左右角色设定、性格与气质、4 字角色标签；所处体系（古风传统 / 都市赛博）；发型；服装从上装写到下装和鞋款；面料材质 | 古风角色用中式传统形制；都市赛博角色必须保留立领/斜襟/盘扣/对襟/襦裙等至少一项中式核心结构，可拼接哑光机能面料；基础造型素颜、少配饰、无夸张光效，便于衍生叠加 |
| 第二段 · 锁定脸部身份 | 「锁定同一张可复用的{年龄}{性别}脸部身份：」开头，依次写脸型、额头、颧骨、下颌与下巴、眼型与瞳色、眼距与眼皮、眉、鼻梁与鼻头、嘴唇、耳朵、肤色肤质、身高与体型 | 必须含约 20 字的「避开同模」差异化特征（如痣、眉尾断眉、下颌偏方、单侧酒窝），防止不同角色出现同一张脸；五官具体到可复现；肤质写 PBR 材质的自然光泽与细腻皮肤纹理 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态 | 结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 本风格渲染锚词、主色调、光线 | 锚词：3D超精致建模、3D国风赛博风格、高精度建模、PBR材质、电影级光影、中式美学核心；古风用中国传统色，都市赛博可加低饱和冷调与极少量可控霓虹点缀；均匀柔光、无硬阴影；避免过曝霓虹、塑料感、蜡感 |

## 三、示例（仅示意写法）

```
陆昭，27岁，男，新长安城数据档案署的夜班修复师，外冷内热的旧档守护者，寡言克制、做事极有分寸，气质清冷沉静，角色标签「守档孤灯」。都市赛博体系下的日常基础造型：墨黑短发，额前碎发略长，后脑发尾收短，无发饰；雾青色中式立领斜襟短衫，盘扣为哑光黑钛合金，衫下拼接一层深灰哑光机能面料，下着黑色直筒束脚长裤，脚穿黑色软底短靴；丝麻与机能面料质感清晰，极简暗纹，无光带、无配饰。

锁定同一张可复用的成年男性脸部身份：窄长脸，额头平整，发际线略高；颧骨微显，下颌线清晰偏方，下巴短而平。深棕色细长眼，眼尾平直，眼距约一只眼宽，内双眼皮，眼神冷静专注；左眉尾有一道细小断眉。鼻梁高挺、鼻头略窄；嘴唇偏薄，唇色淡，右嘴角下方有一颗小痣；耳朵贴头。冷白肤色，PBR 材质的自然光泽，保留细腻皮肤纹理，无磨皮。身高约182cm，肩背平直，身形清瘦修长。

主大头照选择他通宵修复旧档后疲惫却专注的神情：严格正面平视，眼神沉静，唇线平直。主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。

3D超精致建模，3D国风赛博风格，高精度建模，PBR材质，电影级光影，中式美学核心，发丝与面料纹理超清晰；雾青、墨黑与深灰为主色，低饱和冷调，均匀柔光、无硬阴影；避免过曝霓虹、塑料感、蜡感。
```

## 四、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 第一段写明年龄（数字）、性别、身份、角色设定与标签，服装写到下装与鞋款，并保留中式核心形制 |
| R2 | 第二段逐项锁定五官并包含「避开同模」差异化特征 |
| R3 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R4 | 第四段包含本风格锚词（3D超精致建模 / 3D国风赛博风格 / PBR材质 / 电影级光影） |
| R5 | 只输出四段正文 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 写排版/背景/视图/比例/镜头机位，或出现「四视图」「定妆照」「拼图」「多视图」字样（这些由系统模板负责） |
| X2 | 无国风内核的纯西式赛博朋克服饰；基础造型加过曝霓虹、义体改造或身体涂装 |
| X3 | 千人一面、五官描述空泛不可复现 |
| X4 | 夸张表情、动态姿势、场景环境叙事、手持道具 |
| X5 | 输出标题、编号、表格、解释等正文以外的内容 |
