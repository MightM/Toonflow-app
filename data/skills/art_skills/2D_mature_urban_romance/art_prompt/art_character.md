# 二次元人物基础形象（多视图人物需求）生成 · 约束手册

---

## 一、基础形象原则

1. **面容即灵魂** — 五官是角色唯一锚点，精细度适配动画风格
2. **角色为本** — 基础着装由角色描述（身份/职业/性别/场景）决定其常规着装；后续特定服化为叠加层
3. **多视图为锚** — 一张人物多视图（主大头照 + 正/侧/背全身）同时锁定面容、体型、发型和基础服装，是分镜与视频引用的唯一形象
4. **情感传达** — 无妆状态仍需体现角色气质（清冷/温柔/妩媚/冷峻）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 二次元动画风格、赛璐璐上色、低饱和冷色调、电影级构图 |
| 气质 | 必须从角色描述提炼整体气质关键词（如清冷/温润/妩媚），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装由角色描述（身份/职业/性别/场景）决定其最自然的常规着装，作为该角色「日常默认态」；正式服饰/特殊衍生在服化衍生环节叠加。**禁止内衣打底**。

### 着装选择原则

| 角色身份 | 默认着装方向 |
|---|---|
| 学生 | 现代校服 / 学院装 |
| 上班族 | 职业便装（衬衫+裤装/裙装、轻西装） |
| 居家/休闲 | 都市休闲服（卫衣/T恤+牛仔裤/连衣裙） |
| 时尚/约会 | 都市时髦着装 |
| 特殊职业 | 对应身份服装（医生/警察/教师等） |
| 角色描述未明确 | 都市常服、低饱和冷色调 |

### 着装统一规则

- 服装风格须与现代都市二次元美学一致（赛璐璐上色、低饱和冷色调）
- 颜色低饱和，无复杂花纹/装饰，便于后续衍生叠加
- 服装写到下装与鞋款（款式、颜色、材质），全身三视图要完整展示
- 基础服装是「日常默认态」，焦点仍在面容与体态
- 严禁内衣/暴露/性化打底

## 七、输出：人物需求正文

> 系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（16:9 多视图拼图：主大头照 + 正面/侧面/背面全身、纯白背景、构图比例与一致性要求）。所以你**只写人物本身**，不要写排版、背景、视图、比例、镜头位置，也不要写「四视图」「定妆照」「拼图」之类的字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【人物需求】标签本身 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；手持道具 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 身份与造型 | 名字、年龄、身份、性格气质；所处都市场合；素颜无妆；发型；服装从上装写到下装和鞋款；面料材质 | 着装按第六节「着装选择原则」选，低饱和冷色调；写清颜色与材质；明确写「素颜无妆、无发饰、无配饰、无复杂花纹」 |
| 第二段 · 锁定脸部身份 | 「锁定同一张可复用的{年龄}{性别}脸部身份：」开头，依次写脸型、额头与发际线、颧骨与下颌、眼型与瞳色（含高光画法）、双眼皮线与睫毛、眉、鼻梁与鼻尖、唇、耳朵、肤色、体型身材 | 五官由角色描述推导，按二次元都市画法写到可复现（如「狭长凤眼，瞳色深灰带一道冷白高光」「鼻梁线条挺直，鼻尖以小三角阴影表现」）；肤色按第三节写冷白皮/白皙透亮；体型按第四节「身高 - 头身比换算参考」写身高与头身比 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态 | 结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 本风格的渲染锚词与质感、主色调、光线 | 用本手册的风格锚词：二次元动画风格、赛璐璐上色、现代都市风格、低饱和冷色调、强对比度、极致细节、面容与发丝细腻渲染；均匀柔光、无硬阴影；避免正顶硬光、正底光、彩色光，避免肤色发灰或惨白 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜无妆」状态，并声明「无发饰、无配饰」 |
| R2 | 必须根据角色描述声明合适的常规着装（如学生→校服、上班族→职业便装、居家→都市休闲服），并写到下装与鞋款；禁止内衣打底 |
| R3 | 第二段必须逐项锁定脸型与五官（含眼型、瞳色与高光画法），具体到可复现 |
| R4 | 必须声明角色身高并通过头身比约束全身比例（女性默认160-170cm/6.5-7.5头身，男性默认175-185cm/7-8头身） |
| R5 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R6 | 第四段必须包含本风格锚词（二次元动画风格 / 赛璐璐上色 / 现代都市风格 / 低饱和冷色调）与均匀柔光 |
| R7 | 只输出四段正文，不输出任何排版、背景、视图说明 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 内衣/暴露/性化打底；与角色描述明显不符的着装；过度复杂花纹/装饰干扰后续服化叠加 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度美白至无血色 / 肤色发灰 |
| X4 | 写排版/背景/视图/比例/镜头机位，或出现「四视图」「定妆照」「拼图」「多视图」字样（这些由系统模板负责） |
| X5 | 夸张变形表情、动态姿势、场景环境叙事、手持道具 |
| X6 | 忽略身高和头身比约束，身高必须明确声明并通过头身比换算体现全身比例 |
| X7 | 输出标题、编号、表格、解释等正文以外的内容 |
