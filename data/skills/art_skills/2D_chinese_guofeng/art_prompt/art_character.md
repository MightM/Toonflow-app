# 人物基础形象（多视图人物需求）生成 · 约束手册

---

## 一、基础形象原则

1. **造型即灵魂** — 角色造型是核心锚点，国风二次元造型，线条流畅
2. **底模即基础** — 基础打底服装 + 素颜，后续服化均为叠加层
3. **多视图为锚** — 一张人物多视图（主大头照 + 正/侧/背全身）同时锁定面容、体型、发型和基础服装，是分镜与视频引用的唯一形象
4. **古典气质** — 无妆状态仍需体现角色气质（典雅/温婉/英气）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，不预设脸型/眼型/眉型/鼻型/唇型 |
| 风格底色 | 国风二次元、新国潮美学、日式动画渲染、赛璐璐平涂、细腻笔触 |
| 气质 | 必须从角色描述提炼整体气质关键词（如典雅温婉/儒雅英气/侠骨柔情），并写入提示词 |
| 表情 | 中性微表情，符合角色气质 |

## 六、基础服装约束

> 基础服装无特殊约束，女性为素色古装长裙，男性为素色古装长衫。正式服饰在服化衍生环节叠加。

### 女性基础服装

素色古装长裙（交领上襦 + 及地长裙），颜色以基础色为主，无花纹装饰；鞋款为素色布履或素面绣鞋。

### 男性基础服装

素色古装长衫（交领长衫 + 长裤），颜色以基础色为主，无花纹装饰；鞋款为素色布靴或黑色布履。

### 着装统一规则

- 服装风格统一，确保后续服饰叠加无色彩干扰
- 除面部/手部/颈部外基本覆盖
- 服装写到下装与鞋款（款式、颜色、材质），全身三视图要完整展示
- 基础服装仅为安全打底，焦点在面容与体态

## 七、输出：人物需求正文

> 系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（16:9 多视图拼图：主大头照 + 正面/侧面/背面全身、纯白背景、构图比例与一致性要求）。所以你**只写人物本身**，不要写排版、背景、视图、比例、镜头位置，也不要写「四视图」「定妆照」「拼图」之类的字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、Markdown 符号、代码块、解释说明、【人物需求】标签本身 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事；手持道具 |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 | 要点 |
|---|---|---|
| 第一段 · 身份与造型 | 名字、年龄、身份、性格气质；所处朝代氛围；素颜状态；发型；基础服装从上衣写到下裳和鞋履；面料材质 | 服装按第六节写素色古装（女：交领上襦 + 及地长裙 + 素色布履/素面绣鞋；男：交领长衫 + 长裤 + 素色布靴/黑色布履），写清颜色与材质；发色必须墨黑；明确写「素颜、无发饰、无配饰、无花纹装饰」 |
| 第二段 · 锁定脸部身份 | 「锁定同一张可复用的{年龄}{性别}脸部身份：」开头，依次写脸型、额头与发际线、颧骨与下颌、眼型与瞳色（含眼尾走向与高光）、双眼皮线与睫毛、眉、鼻、唇、耳朵、肤色、体型身材 | 五官由角色描述推导，按国风二次元画法写到可复现（如「细长桃花眼，眼尾微挑，瞳色深褐带一点琥珀高光」「鼻梁以细线勾出，鼻尖小巧」）；肤色按第三节写粉白/白皙基调的赛璐璐肤色；体型按第四节写身高与头身比（6–7 头身） |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态 | 结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 本风格的渲染锚词与质感、主色调、光线 | 用本手册的风格锚词：国风二次元、新国潮美学、日式动画渲染、赛璐璐平涂、细腻笔触、发丝线条清晰；中国传统色为主色；均匀柔光、无硬阴影；避免正顶硬光、正底光、冷色光，避免肤色发灰或惨白 |

## 八、示例（仅示意写法，内容按角色描述生成）

沈清辞，20岁，江南医馆的女医，性格温婉沉静、外柔内刚，心怀悲悯又有主见，气质典雅温婉。古代江南春日的日常基础造型：素颜状态；墨黑长发及腰，自然散落于背后，额前两缕细碎鬓发，无发饰；素色浅青交领上襦，月白色素面及地长裙，素色布履；细棉与素绢的衣料纹理清晰，无花纹装饰、无配饰，除面部、颈部与手部外基本覆盖。

主大头照选择她为病人诊脉后沉静思索的神情：正面平视，眼神清亮专注，唇角平和微收。主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」，并声明「无发饰、无配饰」 |
| R2 | 必须声明基础服装（女性：素色古装长裙；男性：素色古装长衫），并写到下装与鞋款 |
| R3 | 发色必须为墨黑 |
| R4 | 第二段必须逐项锁定脸型与五官（含眼型、瞳色与高光画法），具体到可复现 |
| R5 | 必须声明角色身高并通过头身比约束全身比例（女性默认 160-170cm/6-7头身，男性默认 175-185cm/6-7头身） |
| R6 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R7 | 第四段必须包含本风格锚词（国风二次元 / 新国潮美学 / 赛璐璐平涂 / 细腻笔触）与均匀柔光 |
| R8 | 只输出四段正文，不输出任何排版、背景、视图说明 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 基础服装以外的任何服装/配饰/妆容 |
| X2 | 正顶硬光/正底光/冷色光 |
| X3 | 过度美白至无血色 / 肤色发灰 |
| X4 | 写排版/背景/视图/比例/镜头机位，或出现「四视图」「定妆照」「拼图」「多视图」字样（这些由系统模板负责） |
| X5 | 夸张变形表情、动态姿势、场景环境叙事、手持道具 |
| X6 | 忽略身高和头身比约束，身高必须明确声明并通过头身比换算体现全身比例 |
| X7 | 输出标题、编号、表格、解释等正文以外的内容 |
