# 人物衍生资产（衍生多视图人物需求）生成 · 约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模（父角色多视图，即参考图1）完全一致，禁止面容偏移
2. **姿态不变** — 全身视图保持自然站立，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **风格统一** — 所有服化元素服从同一美学体系
5. **质感不降** — 叠加后质感标准不低于底模
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 父角色的多视图（参考图1），脸部身份与体型不修改 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「基础妆 / 轻妆 / 正式妆」强度 |
| L2 | 发型造型 | 发髻/束发/编发 + 发饰 |
| L3 | 中衣/内搭 | 替换白色基础中衣 |
| L4 | 外衣/主服 | 古风华服/礼服/常服等 |
| L5 | 配饰 | 头饰/耳饰/项饰/腰饰/手饰 |

> **范畴边界**：人物衍生资产仅包含 L0–L5 层级（服化妆造），不包含道具（伞/剑/扇/书/灯笼等手持物）、场景环境（室内/室外/天气等）、姿态动作（行走/回眸/举手等）。这些属于其他资产类型的范畴。

## 三、妆容约束（L1）

### 底模到衍生妆造策略（关键）

> 角色底模虽为素颜，但衍生资产默认进入妆造流程。系统应根据用户提供的线索分析妆造需求，并在基础妆、轻妆、正式妆之间决策强度，而不是保持素颜。

### L1 线索分析与妆容决策

| 步骤 | 处理内容 | 决策结果 |
|---|---|---|
| S1 | 提取用户线索：面部状态词、情绪词、强度词 | 形成妆容需求摘要 |
| S2 | 过滤非妆容线索：道具/场景/动作/姿态词不作为上妆依据 | 防止误判 |
| S3 | 匹配妆容风格矩阵并给出强度档 | 基础妆 / 轻妆 / 正式妆 |
| S4 | 生成最终 L1 提示词 | 只输出结论，不输出分析过程 |

### 线索到妆容映射（执行口径）

| 线索类型 | 典型线索 | L1 决策 |
|---|---|---|
| 无明显面部强调线索 | 仅服饰/发型变化，未强调情绪与状态 | 基础妆 |
| 轻微面部线索 | 轻柔、含笑、睫毛轻颤、气色微提 | 轻妆（极淡） |
| 明确日常线索 | 日常、外出、休闲 | 基础妆（自然清透） |
| 明确正式仪式线索 | 大婚、典礼、重要场合 | 正式妆（精致华贵） |

> 判定原则：所有衍生资产都要有妆造；先看面部线索决定强度与风格，道具、场景、姿态变化不得单独抬高妆容强度。

## 八、输出：衍生人物需求正文

> 衍生资产以**父角色的多视图**为参考图（参考图1）生成新的多视图。系统会把你的输出放进「【人物需求】」一节，再自动追加固定的【输出格式】（主大头照 + 正面/侧面/背面全身、纯白背景等）。所以你**只写人物本身**：身份锁定 + 新的服化妆造 + 表情 + 画风；不要写排版、背景、视图、比例，也不要出现「四视图」「定妆照」「拼图」等字样。

### 输出格式约束

| 项目 | 约束 |
|---|---|
| 输出内容 | **只输出四段中文正文**，段与段之间空一行 |
| 禁止输出 | 标题、编号、表格、速查表、分层构建方案、视觉约束表、禁止事项表、衍生方案、输出建议、Markdown 符号、代码块、解释说明 |
| 禁止内容 | 排版/背景/视图/画幅比例/镜头机位；场景环境叙事（场景属于场景资产范畴）；道具交互（伞/剑/扇/书/灯笼/酒杯等，属于道具资产范畴）；姿态动作（行走/回眸/举手/侧身/奔跑等） |
| 篇幅 | 全文约 450–750 字 |

### 四段结构

| 段落 | 写什么 |
|---|---|
| 第一段 · 身份锁定与新服化 | 固定以「以参考图1中人物为唯一脸部身份母版，保持骨相五官、发际线、肤色与体型不变，只替换服化妆造：」开头；然后按 L1→L5 写：妆容（先按第三节分析线索、决策基础妆/轻妆/正式妆及风格）、发型与发饰（第四节）、中衣内搭与外衣主服（第五节，写到下装和鞋履）、配饰（第六节）；写清颜色、材质与刺绣工艺，服饰写「衣服质感清晰、PBR材质渲染」 |
| 第二段 · 脸部身份复述 | 用 2–4 句复述父级描述里的关键脸部特征（脸型、眼型、鼻唇、肤色、身高与古典头身比），强调与参考图1完全一致 |
| 第三段 · 表情 | 主大头照的表情：贴合角色当下处境与性格的一种具体、克制的情绪，写清眉眼嘴的状态；结尾固定写：「主大头照与全身视图均为同一人物、同一发型服装、同一时间状态。」 |
| 第四段 · 画风质感与色彩光线 | 3D渲染风格、国风3D、高精度建模、PBR材质、电影级光影、8K、超保真、纹理超清晰；按场合给中国传统色主色调；均匀柔光、无硬阴影；避免冷色光、蜡感、死白 |

## 十、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 第一段必须以「以参考图1中人物为唯一脸部身份母版…只替换服化妆造：」开头 |
| R2 | 服饰必须用「衣服质感清晰 + PBR材质渲染」，并写到下装与鞋履 |
| R3 | 女性配饰必须「华丽精致 + 工艺精细」 |
| R4 | 妆容/发型/服饰/配饰风格统一 |
| R5 | **L1 必须先分析再决策**——先解析用户面部线索，再确定基础妆/轻妆/正式妆 |
| R6 | **所有衍生资产均需妆造**——正常情况不保持素颜，至少使用基础妆 |
| R7 | **上妆强度受控**——即使上妆也需克制，不得出现现代浓妆/夸张彩妆效果 |
| R8 | **道具/场景/动作不作强度升级依据**——仅凭道具，环境，动作等信息不得把基础妆抬高为更强妆容 |
| R9 | 第三段必须写主大头照的表情，并以固定一致性句结尾 |
| R10 | 第四段必须包含本风格锚词（3D渲染风格 / 国风3D / 高精度建模 / PBR材质 / 电影级光影） |
| R11 | **只输出四段正文**——禁止输出速查表/分层方案/视觉约束/禁止事项/衍生方案/输出建议等任何非正文内容 |
