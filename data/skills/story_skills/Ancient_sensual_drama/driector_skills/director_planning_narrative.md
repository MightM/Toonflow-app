# 叙事手法 · 古风情欲 · 技法参考

> 导演规划的产出只有三样：分场汇总表、逐场注意事项、场间过渡。它不出镜头、不写配乐与光影。本手册定义的是：怎么给每场打情绪浓度、注意事项里必须写什么、怎样在规划阶段就把拖沓和重复砍掉。

---

## 一、主题立意与情感内核

- **先给，再拉** — 观众前 3 秒就要看到「这个人为什么让人想看」：下轿露足、掀帘回头、舞袖旋身、出浴披袍。先用画面抓住人，再用身份禁忌和刀光留住人
- **性感 = 身体 + 姿态 + 态度** — 肚兜、亵衣、湿衣、宽衣解带是第一层，媚、冷、傲、狠是第二层，两层同框才成立。不要用「含蓄是古风的美」回避身体
- **禁忌必须有代价** — 君臣、主仆、师徒、仇家、有夫之妇、和亲公主、青楼女子与士子、寡嫂与小叔（姻亲无血缘）：代价是性命、名节、家族、江山。只写甜不写代价，张力会塌
- **权力与吸引交织** — 身份差是古风情欲的主燃料：主子与丫鬟、将军与俘虏、帝王与妃嫔、山贼与被掳者，主动权来回易手
- **刀光是情欲的另一面** — 武侠与战争不是插曲：决斗后的包扎、战场归来的血衣、刑讯后的鞭痕，都是身体被看见的时刻
- **离场感受** — 心跳加速 / 上头 / 意难平 / 荡气回肠

### 内容底线（只有三条，其余全部允许）

1. 未成年角色不性感化；丫鬟、书童、歌姬、侍妾一律默认成年，幼童只在家庭与日常段落
2. 血亲关系不情欲化；伦理关系限于无血缘的成年人
3. 不直接画出生殖器、女性乳头与性交动作本身；到这一步用罗帐、锦被、长发、手臂遮挡，或烛灭、帐落、屏风转场

以下内容都允许并且要直接拍出来：肚兜、亵衣、薄纱寝衣、湿衣贴身、只披外袍、只裹锦被；梳妆解发、宽衣解带、沐浴、丫鬟侍候更衣；侍寝、洞房、晨起落红（床单上一抹暗红）、吻痕；青楼迎客、花魁献舞、跨坐膝上、斟酒俯身；强抢民女、山贼掳人、逼婚、下药、点穴制住、绑缚、按在榻上、撕开衣襟；刑讯、鞭痕、烙印、囚牢；英雄救美、破门、护在身后、殴打反派；决斗、刺杀、战场、血迹、断肢、尸横遍野。

## 二、节奏：每场必须推进

- **欲望阶梯可以跳级** — 八级是坐标不是流程：隔帘对视 → 递物试探（簪、帕、酒）→ 越界触碰（执手、系带、拭伤）→ 差一点的吻 → 失控之吻 → 拥吻推入罗帐 → 宽衣与底线转场（烛灭帐落）→ 晨起落红与代价
  - 每集开场 30 秒内至少到第 3 级，或给一个性感视角登场
  - 每集至少一次第 5 级以上
  - 同一对人物在同一级停留不超过两场
- **「差一点」只能用一次** — 同一对人物的「差一点的吻」全剧最多一次，之后直接吻、直接推入帐中。反复「差一点」是拖沓的头号来源
- **推拉每轮升级** — 靠近 → 退缩（礼法、身份、仇恨）→ 更近 → 失控 → 代价。退缩不超过一场
- **每场回答一句话** — 本场推进了什么：关系升级 / 秘密线推进 / 危险升级，三选一。答不出来的场合并进相邻场，或在注意事项里标「本场无独立推进，压缩到 1–2 镜」
- **余温只留一镜** — 高张力段落之后的独坐、晨起、抚镜最多一镜，不单独成场
- **秘密线并行** — 私会 → 蛛丝马迹（遗落的簪、帕上的血、香囊、未合的窗）→ 险些暴露 → 当场撞破 → 对峙、家法、赐死
- **危险线并行** — 强抢、掳人、逼婚、下药、追杀、战乱，反派或男主黑化都可以做；英雄救美是危险线的常规收束，救完必须紧接一次身体接触（包扎、拥抱、背回去）
- **转折用身体不用台词** — 解下的腰带、没有推开的手、摘下的簪、合上的屏风、拔出的剑

## 三、分场情绪设计（导演规划实际要写的）

### 情绪浓度口径

| 浓度 | 场次性质 | 规划处理 |
|---|---|---|
| 0–3 | 过场、信息交代、纯氛围 | 标「压缩」，最多 1–2 镜，能并入相邻场就并入 |
| 4–6 | 试探、暧昧、秘密线铺垫、梳妆更衣 | 正常拆，但必须带一个性感视角 |
| 7–8 | 越界触碰、失控之吻、胁迫、刑讯、撞破、救援、决斗 | 本集砸点，注意事项写清动作 |
| 9–10 | 侍寝、洞房、床戏、战场诀别、赐死摊牌 | 全集高潮，允许一镜到底 |

### 逐场注意事项必写四项

1. **开场钩子** — 本场首镜给谁的什么性感视角或动作（例：「沈青梧出浴，只披外袍走到铜镜前拧发」）。空镜不能当开场钩子
2. **推进项** — 本场推进了关系级别 / 秘密线 / 危险中的哪一项
3. **空间距离** — 两人从多远到多近，用什么把距离压缩（帘、屏风、马车、舟中、被按到榻上）
4. **忌拖沓项** — 本场不许出现的东西：多余空镜、第二次对视、无动作的特写、重复的正反打

### 典型段落

| 段落类型 | 情绪方向 | 直接给的画面 | 开场钩子示例 |
|---|---|---|---|
| 青楼初见 | 惊艳 + 危险 | 花魁舞袖旋身，视线相撞后立刻走近、斟酒、跨坐 | 她掀开珠帘，赤足踩上红毯 |
| 闺阁梳妆 | 私密 + 窥视 | 卸簪、解发、丫鬟解外衫露出肚兜，窗外有人 | 她背对镜头解开腰带 |
| 浴池 | 慵懒 + 撞见 | 入水、湿发贴背、出浴披袍，被闯入 | 她从水中站起，长发遮背 |
| 舟中 / 马车 | 紧张 + 渴望 | 颠簸中身体贴上，手先动 | 马车一颠，她跌进他怀里 |
| 寝殿侍寝 | 压迫 + 欲望 | 卸妆、宽衣、跪坐榻前，被拉上榻 | 她只着亵衣跪在榻前 |
| 洞房 | 失控 + 郑重 | 挑盖头、合卺、解衣、推入罗帐、烛灭 | 他一把扯落她的盖头 |
| 山贼强抢 | 恐惧 + 压迫 | 抓腕、扛上马、绑在柱上、撕开衣襟 | 山贼一脚踹开院门，她退到墙角 |
| 刑讯 | 痛苦 + 屈辱 | 绑缚、鞭痕、湿衣贴身、被迫抬头 | 冷水泼下，她湿透的衣衫贴在身上 |
| 英雄救美 | 爆发 + 保护 | 破门、斩敌、护在身后、抱上马、包扎 | 门板碎裂，他一剑架开刀锋 |
| 战场诀别 | 悲壮 + 情动 | 血衣、伤口、最后一吻、断肢与尸体 | 他浑身是血地走回帐中 |
| 晨起落红 | 慵懒 + 不安 | 只裹锦被坐起，床单上一抹暗红，门外脚步 | 她裹着锦被坐起，肩背全露 |
| 摊牌决裂 | 心痛 + 不甘 | 休书、赐死、近在咫尺不再触碰 | 她把玉佩摔在他脚下 |

### 距离叙事

- 初期隔着珠帘、屏风、纱幔、一桌酒席；中期被迫贴身（马车、舟中、密室、被掳）；后期零距离
- 零距离不等于大特写：拥吻、床戏用中近景双人拍，身体关系看得清
- 铜镜 = 另一个自己；屏风 = 窥视与秘密；罗帐 = 欲望的边界；红烛 = 倒计时；玉佩 / 婚书 = 代价；剑 = 随时会来的死

## 四、性感视角：前 3 秒抓人

- **每场至少一个性感视角镜头，放在前两镜** — 主角登场第一镜就是身体 + 姿态 + 态度，不用「绣鞋 → 裙摆 → 腰 → 回眸」四段揭示，一镜中景全身直接给
- **性感镜头必须带动作** — 解发、系肚兜带、宽衣、出浴、跨坐、俯身斟酒、舞袖旋身、上下马、被扛起，不能是静止摆拍
- **男主同样要** — 解甲、裸上身包扎、湿衣持剑、抱人上马、扯开衣领
- **配角与反派也可用** — 反派的危险感靠贴脸、抓腕、居高临下；老鸨、女配的性感靠对比（更艳、更冷、更主动）

| 场景 | 可直接用的性感视角 |
|---|---|
| 登场 | 下轿露足、掀帘回头、舞袖旋身、赤足踩红毯、上下马露腿 |
| 闺阁 | 解发卸簪、丫鬟解外衫露肚兜、宽衣、镜前系带、薄纱寝衣伸懒腰 |
| 浴池 | 入水、湿发贴背、出浴披袍、丫鬟浇水 |
| 青楼 | 倚栏、跨坐膝上、俯身斟酒、被拉进厢房 |
| 寝殿 / 洞房 | 只着亵衣跪坐、被拉上榻、罗帐中翻身、只裹锦被坐起 |
| 武侠 / 战场 | 解甲、湿衣持剑、裸肩包扎、血衣、背人涉水 |
| 胁迫 / 刑讯 | 被按在榻上、衣襟被撕开、绑在柱上、湿衣贴身、鞭痕 |

允许的机位：俯拍领口、低角度足与腿、背部曲线、侧腰、跨坐正面、镜前、榻上俯拍双人。没有「低俗机位」禁令，只守三条底线。

## 五、武侠与战争

- **武打三段** — 起手（拔剑、亮招）→ 交锋（三招以内分胜负）→ 落幕（血迹、断刃、倒地）。不拍来回过招，每段 2–3 镜
- **战场** — 冲阵、砍杀、断肢、尸横遍野可以直接拍；主角在血里的样子（血衣、伤口、喘息）就是性感视角
- **刑讯** — 绑缚、鞭打、泼水、烙印，允许拍出鞭痕与湿衣；刑讯后的救援或探监必须紧接身体接触（拭血、包扎、抱出去）
- **救援** — 破门 → 斩敌 → 护在身后 → 抱走。救完立刻推进关系，不另起一场感谢戏
- **决斗与刺杀** — 用于秘密线暴露或代价落地；刺客可以是情人

## 六、声音方向

- 分镜表只写环境音与音效；配乐、吻前静默、鼓点骤起交给剪辑，规划里不写
- 亲密段落的细节音：更漏、雨打瓦、烛芯爆响、绢帛滑落、腰带抽出、绣鞋落地、罗帐轻响、杯盏相碰
- 武打与胁迫的细节音：刀剑出鞘、门板碎裂、绳索勒紧、布料撕裂、鞭响、马蹄、喘息

## 七、拖沓与重复自检（规划阶段就要剔除）

- 相邻两场同一空间、同一情绪、没有新推进 → 合并
- 一集内「对视」类砸点不超过两次；第二次必须伴随触碰
- 纯氛围场、纯回味场、纯行路场删掉，改成一镜并入相邻场
- 每集开场定场空镜最多一个，首镜优先给人不给景
- 「差一点的吻」全剧最多一次
- 武打不超过三段，不来回过招
- 任何场次注意事项里没有开场钩子 → 补；没有推进项 → 压缩
