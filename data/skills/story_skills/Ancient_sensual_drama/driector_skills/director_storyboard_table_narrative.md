# 分镜表叙事手法 · 古风情欲 · 技法参考

---

## 一、定位：分镜表写「拍什么」，不写「怎么剪」

- **分镜表只写有动作的镜头**。停顿、慢动作、升格、缓推特写、烛光下的凝视、呼吸交错、黑场一秒、音乐抽离，全部交给剪辑用变速、延长、重复帧实现。分镜表里不得出现以时间流逝为内容的镜头
- **禁用词**（画面描述与运镜字段都不能出现）：停顿、静止、缓慢、极慢、升格、慢动作、凝视 N 秒、呼吸交错、时间被拉长、给观众时间、留白、意境
- **理由** — AI 生成时，没有动作的特写会出现面部漂移、手指错乱、表情僵住，长镜头浪费生成额度还不稳定；节奏是剪辑的事，不是分镜的事
- 丫鬟、书童、歌姬、侍妾一律成年；三条底线见第八节

---

## 二、镜头预算：每镜必须推进

- **每镜三选一** — 新信息（谁来了、看到了什么）/ 关系升级（更近、更越界）/ 危险升级（更紧、更快暴露、刀更近）。三样都没有的镜头删
- **片段 ≤ 15s，每片段 2–4 镜，每镜 2–5s** — 一场镜头数上限 ≈ 该场估算时长 ÷ 4
- **空镜** — 每场最多 1 个，每集最多 2 个，只在跨时空时用；同场景内不插空镜；山水楼阁不能当开场
- **反应镜** — 只在台词跨镜时用；没有台词的反应镜必须带动作（攥紧帕子、别开脸、按住剑柄、解下一枚簪）
- **定场** — 主角在场时首镜给人不给景；环境通过人物身后的纵深交代（珠帘、屏风、军帐、城墙）

---

## 三、去重规则

- **相邻镜头三要素至少换两项** — 景别 / 机位方向（正、侧、过肩、俯、仰）/ 主体（谁在画面里）
- **同一人物同一景别不得连续两镜**
- **同一动作只拍一次** — 不再「差一点 → 再差一点」「隔帘对视 → 又对视」；动作要么发生，要么被打断，被打断之后下一次就是发生
- **正反打最多两轮** — 第三轮必须换机位（过肩 → 侧面双人 → 俯拍）或换动作（一方起身、走近、伸手、拔剑）
- **同一场里「对视」最多一次，「手部特写」「唇部特写」各最多一次**
- **登场一镜完成** — 中景全身直接给，不拆成「绣鞋 → 裙摆 → 腰 → 回眸」
- **武打不来回过招** — 起手、交锋、落幕各一到两镜，三招内分胜负
- **自检方法** — 写完后把每镜列成「景别 + 主体 + 动作」三元组，任何两镜相同就删一个

---

## 四、景别与机位

- **默认中景、中近景、近景** — 双人戏用过肩、侧面双人、俯拍榻上双人；拥吻用中近景双人，不用唇部特写
- **特写只在动作发生在局部时用，且 ≤ 3s** — 手解腰带、系肚兜带、拔簪、手探进衣襟、绳索勒进手腕、床单上一抹暗红、剑尖抵住咽喉
- **大特写（唇、眼）不进分镜表** — 需要时剪辑从近景推
- **性感机位全部允许** — 俯拍领口、低角度足与腿、背部曲线、侧腰、跨坐正面、镜前、榻上俯拍、出浴仰拍；没有「低俗机位」禁令
- **前景遮挡** — 珠帘、屏风缝、纱幔、窗棂、另一个人的肩膀，用来制造窥视感，但遮挡后画面里仍要有动作

| 场景 | 直接可写的性感镜头 |
|---|---|
| 登场 | 下轿露足 / 掀帘回头 / 舞袖旋身 / 赤足踩红毯 / 上下马露腿 |
| 闺阁 | 解发卸簪 / 丫鬟解外衫露肚兜 / 镜前系带 / 薄纱寝衣伸懒腰 |
| 浴池 | 入水 / 湿发贴背 / 出浴披袍 / 丫鬟浇水 |
| 青楼 | 倚栏 / 跨坐膝上 / 俯身斟酒 / 被拉进厢房 |
| 寝殿 / 洞房 | 只着亵衣跪坐 / 被拉上榻 / 罗帐中翻身 / 只裹锦被坐起 |
| 武侠 / 战场 | 解甲 / 湿衣持剑 / 裸肩包扎 / 血衣 / 背人涉水 |
| 胁迫 / 刑讯 | 被按在榻上 / 衣襟被撕开 / 绑在柱上 / 冷水泼下湿衣贴身 / 鞭痕 |

## 五、开场 3 秒

- **每集首镜、每场首镜** — 主角登场第一镜 = 性感视角 + 动作 + 态度。不用空镜开场，除非跨时空非用不可
- **性感镜头必须带动作** — 解发、宽衣、出浴、跨坐、俯身、旋身、上下马、被扛起、拔剑；静止摆拍不算
- **男主同样** — 解甲、扯开衣领、裸上身包扎、湿衣持剑、抱人上马

| 场景 | 首镜示例 |
|---|---|
| 青楼初见 | 沈青梧掀开珠帘，赤足踩上红毯，舞袖一甩扫过萧决的脸 |
| 闺阁夜 | 苏婉儿背对镜头解开腰带，外衫滑到肘间，回头看向窗外 |
| 浴池 | 柳含烟从水中站起，长发贴着背，伸手去够架上的外袍 |
| 山寨 | 黑虎一脚踹开柴门，春桃退到墙角，手背在身后摸到剪刀 |
| 军帐 | 萧决浑身是血地掀帐进来，单手解开铠甲的系带 |

## 六、运镜

- **运镜字段只写**：固定 / 缓推 / 缓拉 / 跟随 / 环绕 / 摇 / 手持 / 焦点转移。不写升格、慢动作、迷离、失焦、漂浮（这些是后期）
- **运镜跟着动作走** — 缓推只配动作（她边解带边走来）；环绕只配动作（拥吻中退入罗帐）；不能用运镜「让镜头慢下来」
- **一镜到底** — 只用于连续位移（长廊 → 推门 → 进殿 → 被压到屏风上；冲阵 → 斩敌 → 抱人上马），8–12s，每集最多一处
- **焦点转移** — 前景玉佩 / 酒盏 / 剑 → 后景人物，标注「焦点转移：前景 X → 后景 Y」，本身就是一次信息推进，不算静止镜头

---

## 七、时长

| 镜头类型 | 时长 | 说明 |
|---|---|---|
| 动作镜 | 2–4s | 一个动作完成即切 |
| 台词镜 | 按 4 字 / 秒 | 长台词按语义拆镜 |
| 性感登场 | 3–4s | 一镜全身 + 动作 |
| 吻 / 推入罗帐 | 3–5s | 含推倒、抵屏风动作 |
| 武打单段 | 2–3s | 起手、交锋、落幕各一段 |
| 特写 | ≤ 3s | 必须带局部动作 |
| 空镜 | 2s | 只在跨时空用 |
| 一镜到底 | 8–12s | 每集最多一处 |

- **3 秒规则** — 3 秒内没有新动作或新信息就切镜。没有「黄金 6 秒」，没有「停顿本身就是戏」
- **单镜不超过 5s**（一镜到底除外）

## 八、亲密、武打与冲突动作（直接写）

- **拥吻拆两镜** — ① 中近景双人：吻落下，手探进衣襟或攥住衣带 ② 双人：推入罗帐、抵在屏风、抱起，镜头跟随
- **宽衣床戏拆三镜** — ① 脱外层：解腰带、褪外袍、解肚兜带、亵衣滑落肩头 ② 双人翻身压上，罗帐、锦被、长发、手臂遮挡 ③ 底线转场：烛灭 / 帐落 / 锦被拉起 / 屏风合上。时长合计 ≤ 12s
- **侍寝** — 跪坐榻前卸簪 → 被拉上榻 → 同上三镜
- **晨起落红** — 只裹锦被坐起 → 床单上一抹暗红（特写 ≤ 3s）→ 门外脚步或推门。三镜，写作「床单上一抹暗红」
- **胁迫拆三镜** — ① 压迫：抓腕、按在榻上、贴脸威胁、剑抵咽喉 ② 挣扎：踢打、撕扯、衣襟被撕开、点穴制住 ③ 结果：得逞被打断 / 救援破门。每镜 2–3s，节奏快
- **刑讯** — 绑缚 → 鞭打或泼水 → 湿衣与鞭痕（中近景），不超过三镜；探监或救援紧接拭血、包扎、抱出
- **武打拆三镜** — ① 起手：拔剑、亮招 ② 交锋：一次碰撞或一次压制 ③ 落幕：血溅、断刃、倒地。战场可加一镜尸横遍野的纵深
- **救援** — 破门 → 斩敌或击倒 → 护在身后 / 抱起 → 包扎或拥抱。允许砍杀反派、流血、断肢
- **单镜动作不超过两个** — 「攥住衣带 + 吻上去」可以；「抬眼 + 起身 + 走近 + 吻」拆镜

### 三条底线（唯一的禁止项）

1. 未成年角色不参与任何上述亲密、性感或刑讯镜头
2. 血亲之间不写亲密动作
3. 不直接画出生殖器、女性乳头与性交动作本身；到这一步写遮挡（罗帐、锦被、长发、手臂）或底线转场

## 九、台词

- 亲密段落台词短（≤ 12 字）、低声、可标注「低声」「贴耳」「气声」；古白话，不堆文言
- 潜台词优先 —「大人该回了」比「留下」更撩人
- 一句台词对应一个镜头，切换说话者时切镜头
- 沉默不写成镜头；吻前的静默由剪辑做
- 内心独白配动作镜（解带、拭剑、抚镜），不配嘴不动的近景

---

## 十、转场

- **默认硬切**，同场内一律硬切
- **底线转场只在触到第三条底线时用** — 烛灭、帐落、锦被拉起、屏风合上、门扉阖上落幅在门缝烛光；1–2s，每集最多两次。不是每场亲密戏都要转场，拥吻、推入罗帐、褪外袍直接拍完
- **跨时空** — 一个 2s 空镜或直接叠化（叠化由剪辑做，分镜表只标「切下一场」）
- **不写意境转场**（水墨晕开、花瓣飘落再对焦是后期）

---

## 十一、写完自检

- 每镜都有可见动作？没有「停顿 / 静止 / 缓慢 / 升格 / 凝视 / 呼吸交错 / 意境」？
- 相邻两镜三要素至少换了两项？同一人物同一景别没有连续两镜？
- 每场「对视」≤ 1，「手部特写」「唇部特写」各 ≤ 1，空镜 ≤ 1？
- 每集首镜、每场首镜是性感视角 + 动作？山水楼阁没有当开场？
- 特写 ≤ 3s 且带动作？没有唇、眼大特写？
- 单镜 ≤ 5s？一镜到底 ≤ 1 处？武打没有来回过招？
- 每镜能说出推进了什么？说不出的删了吗？
- 正反打没有超过两轮？
- 只有三条底线，其余宽衣、侍寝、落红、胁迫、刑讯、血迹都直接写了？
