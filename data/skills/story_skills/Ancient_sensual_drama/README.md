# 古风情欲 · 导演叙事手法技能包

## 简介

本技能包为 **古风情欲** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。聚焦古代背景下成年男女的情欲拉扯、身份禁忌、青楼与闺阁、侍寝与洞房、武侠恩仇与战场血色。推荐搭配视觉手册「古风魅惑 · 超写实真人」，也适用于其他古风写实类视觉风格。

## 核心理念

- **先给，再拉** — 前 3 秒就要用身体、姿态、眼神抓住观众：下轿露足、掀帘回头、宽衣解带、出浴披袍；性感不靠人设慢慢铺
- **每镜必须推进** — 新信息、关系升级、危险升级三选一，三样都没有的镜头删；欲望阶梯可以跳级，「差一点的吻」全剧只用一次
- **分镜表写「拍什么」，不写「怎么剪」** — 停顿、慢动作、升格、静止特写、烛光下的凝视交给剪辑；分镜表只写有动作的镜头
- **不重复** — 相邻镜头景别 / 机位 / 主体至少换两项，同一动作只拍一次，正反打最多两轮
- **禁忌与刀光制造张力** — 君臣、主仆、师徒、仇家、有夫之妇、和亲公主，身份越重一次执手越撩人；武侠与战争的血是情欲的另一面

## 内容底线（只有三条，其余全部允许）

1. 未成年角色不性感化；丫鬟、书童、歌姬、侍妾一律默认成年，幼童只在家庭与日常段落
2. 血亲关系不情欲化；伦理关系限于无血缘的成年人（姻亲、义结、师徒、主仆均可）
3. 不直接画出生殖器、女性乳头与性交动作本身；到这一步用罗帐、锦被、长发、手臂遮挡，或烛灭、帐落、屏风转场

肚兜、亵衣、薄纱寝衣、湿衣贴身、宽衣解带、沐浴、梳妆、侍寝、洞房、落红、青楼、丫鬟侍候更衣、强抢民女、绑缚、下药、点穴制住、刑讯鞭痕、英雄救美、决斗、刺杀、战场血迹、断肢、尸体，都直接写进规划与分镜表。

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义古风情欲在情绪浓度、逐场注意事项、节奏推进与性感钩子上的规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与情感内核 | 先给再拉、性感 = 身体 + 姿态 + 态度、古风禁忌类型、三条内容底线与允许清单 |
| 节奏：每场必须推进 | 古风欲望阶梯可跳级、「差一点」只用一次、每场回答推进了什么、余温只留一镜 |
| 分场情绪设计 | 情绪浓度口径、逐场注意事项必写四项、青楼 / 闺阁 / 浴池 / 寝殿 / 洞房 / 战场等典型段落与开场钩子 |
| 性感视角 | 每场前两镜给性感视角、性感镜头必须带动作、按场景的视角清单、允许的机位 |
| 武侠与战争 | 武打三段、战场血色、刑讯与救援怎样为情欲线服务 |
| 声音方向 | 分镜表只写环境音与音效，配乐与静默交给剪辑 |
| 拖沓与重复自检 | 规划阶段就合并、压缩、删除 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义古风情欲分镜表的镜头预算、去重、景别机位、开场钩子、时长与亲密 / 武打 / 胁迫动作写法。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 只写有动作的镜头，停顿 / 慢动作 / 升格交给剪辑，禁用词清单 |
| 镜头预算 | 每镜三选一推进、片段与镜头数上限、空镜与反应镜限额 |
| 去重规则 | 相邻镜头三要素换两项、同一动作只拍一次、正反打最多两轮、登场一镜完成 |
| 景别与机位 | 默认中近景，特写 ≤ 3s 且带动作，大特写不进分镜表，性感机位全部允许 |
| 开场 3 秒 | 每集 / 每场首镜 = 性感视角 + 动作 + 态度 |
| 运镜 | 只写基础运镜，跟着动作走，一镜到底每集最多一处 |
| 时长 | 2–5s，3 秒规则，单镜不超过 5s |
| 亲密、武打与冲突动作 | 拥吻两镜、宽衣床戏三镜、胁迫三镜、武打三镜、救援；允许动作清单；三条底线 |
| 台词与转场 | 短句、沉默不写成镜头；默认硬切，烛灭 / 帐落转场每集最多两次 |

## 使用方式

本技能包作为 ToonFlow 导演 AI 的叙事手法参考，在生产流程中自动加载，指导：

1. **叙事规划** — 确定欲望主线、危险线、性张力节点与场景情绪
2. **分镜表生成** — 根据叙事规划输出具体的景别、运镜、时长、亲密与武打动作拆解与转场方案
