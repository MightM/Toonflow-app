# 都市情欲 · 导演叙事手法技能包

## 简介

本技能包为 **都市情欲** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。聚焦成年男女之间的暧昧拉扯、伦理禁忌、接吻与亲密动作、性张力与迷幻氛围。推荐搭配视觉手册「都市魅惑 · 超写实3D真人」，也适用于其他写实类视觉风格。

## 核心理念

- **欲望是引擎** — 每一场戏都要回答"他们有多想靠近、又为什么不能靠近"，欲望与阻力的拉扯推动剧情
- **禁忌制造张力** — 身份、关系、秘密、道德代价越重，一次对视、一次触碰就越撩人
- **差一点比得到更撩人** — 嘴唇相距一厘米的停顿，比完整的吻更让人上头；每一级亲密都要先"差一点"
- **留白是最高级的性感** — 最炽热的时刻交给关门、灯熄、窗帘落下与次日清晨，让观众自己完成想象
- **迷幻是情绪放大器** — 夜店灯光、微醺、梦境与幻想段落，把欲望从现实里抽离出来放大

## 内容边界（全流程强制）

- 所有角色为成年人（设定年龄 ≥ 22 岁），禁止任何未成年或幼态化呈现
- 「伦理」仅限**成年人之间无血缘关系**的禁忌关系：婚外情/出轨、前任复燃、上下级、闺蜜或兄弟的伴侣、无血缘的成年继亲、契约婚姻等；**严禁血亲关系的情欲化**
- 亲密必须是双方意愿；强迫、胁迫、下药不得被浪漫化或性感化（只能作为反派恶行被阻止、被惩罚）
- 画面亲密上限：深情拥吻、隔着衣物抚摸（脸颊/颈/腰/背/腿）、衣着完整地相拥倒向沙发或床、贴颈耳语、遮挡完整的事后余温；更进一步一律用转场暗示
- 严禁：裸露、脱衣过程、性行为或性动作、体液；迷幻段落不描写毒品使用

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义都市情欲在主题立意、欲望节奏、场景情绪设计与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与情感内核 | 欲望与克制、禁忌的代价、权力与吸引、离场感受 |
| 叙事结构与节奏规划 | 欲望阶梯八级、推拉模型、性张力节点分布、伦理冲突线 |
| 分场景情绪设计 | 九大典型情欲段落、距离叙事、空间隐喻 |
| 声音与音乐方向 | 呼吸与布料声优先、R&B/贝斯脉冲、迷幻声效处理 |
| 构图与景别叙事 | 局部特写组、窥视构图、双人剪影、景别递进 |
| 镜头运动与节奏 | 慢推、环绕拥吻、焦点转移、升格、迷幻运镜 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义都市情欲在分镜表中的景别递进、运镜节奏、时长把控、亲密互动拆解与转场逻辑。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为性张力节奏控制工具的定位说明 |
| 景别选择 | 由下至上揭示、局部特写组、亲密景别递进 |
| 运镜节奏 | 慢推、环绕拥吻、焦点转移、升格 |
| 时长把控 | 对视、吻、留白转场的时长参考 |
| 镜头合并策略 | 去 AI 感、张力密度优先 |
| 一镜到底 | 长廊跟随进门、环绕拥吻 |
| 人物互动设计 | 亲密动作拆解、允许与禁止动作清单 |
| 台词与留白 | 低声气声、潜台词、沉默的张力 |
| 转场设计 | 关门/灯熄/窗帘/清晨叠化、迷幻光斑转场 |

## 使用方式

本技能包作为 ToonFlow 导演 AI 的叙事手法参考，在生产流程中自动加载，指导：

1. **叙事规划** — 确定欲望主线、性张力节点、场景情绪与音乐方向
2. **分镜表生成** — 根据叙事规划输出具体的景别、运镜、时长、亲密动作拆解与转场方案

> 剧本阶段的题材规则位于全局剧本技能文件末尾的「题材附加规则 · 都市情欲」章节，当项目画风为「都市魅惑 · 超写实3D真人」或风格定位为「都市情欲」时启用。
