# 分镜表叙事手法 · 都市情欲 · 技法参考

---

## 一、定位：分镜表写「拍什么」，不写「怎么剪」

- **分镜表只写有动作的镜头**。停顿、慢动作、升格、缓推特写、凝视、呼吸交错、黑场一秒、音乐抽离，全部交给剪辑用变速、延长、重复帧实现。分镜表里不得出现以时间流逝为内容的镜头
- **禁用词**（画面描述与运镜字段都不能出现）：停顿、静止、缓慢、极慢、升格、慢动作、凝视 N 秒、呼吸交错、时间被拉长、给观众时间、留白
- **理由** — AI 生成时，没有动作的特写会出现面部漂移、手指错乱、表情僵住，长镜头浪费生成额度还不稳定；节奏是剪辑的事，不是分镜的事
- 所有角色为成年人；三条底线见第八节

---

## 二、镜头预算：每镜必须推进

- **每镜三选一** — 新信息（谁来了、看到了什么）/ 关系升级（更近、更越界）/ 危险升级（更紧、更快暴露）。三样都没有的镜头删
- **片段 ≤ 15s，每片段 2–4 镜，每镜 2–5s** — 一场镜头数上限 ≈ 该场估算时长 ÷ 4
- **空镜** — 每场最多 1 个，每集最多 2 个，只在跨时空时用；同场景内不插空镜
- **反应镜** — 只在台词跨镜时用；没有台词的反应镜必须带动作（攥紧杯子、别开脸、解开一颗扣）
- **定场** — 主角在场时首镜给人不给景；环境通过人物身后的纵深交代

---

## 三、去重规则

- **相邻镜头三要素至少换两项** — 景别 / 机位方向（正、侧、过肩、俯、仰）/ 主体（谁在画面里）
- **同一人物同一景别不得连续两镜**
- **同一动作只拍一次** — 不再「差一点 → 再差一点」「对视 → 又对视」；动作要么发生，要么被打断，被打断之后下一次就是发生
- **正反打最多两轮** — 第三轮必须换机位（过肩 → 侧面双人 → 俯拍）或换动作（一方起身、走近、伸手）
- **同一场里「对视」最多一次，「手部特写」「唇部特写」各最多一次**
- **登场一镜完成** — 中景全身直接给，不拆成「鞋 → 腿 → 腰 → 回眸」
- **自检方法** — 写完后把每镜列成「景别 + 主体 + 动作」三元组，任何两镜相同就删一个

---

## 四、景别与机位

- **默认中景、中近景、近景** — 双人戏用过肩、侧面双人、俯拍床上双人；拥吻用中近景双人，不用唇部特写
- **特写只在动作发生在局部时用，且 ≤ 3s** — 手解扣、拉丝袜、手指勾领带、口红印、摘婚戒、手探进衬衫下摆、皮带扣被解开
- **大特写（唇、眼）不进分镜表** — 需要时剪辑从近景推
- **性感机位全部允许** — 俯拍领口、低角度腿部、背部曲线、侧腰、跨坐正面、镜前更衣、湿身、床上俯拍；没有「低俗机位」禁令
- **前景遮挡** — 门缝、镜面、纱帘、另一个人的肩膀，用来制造窥视感，但遮挡后画面里仍要有动作

| 场景 | 直接可写的性感镜头 |
|---|---|
| 登场 | 中景全身走来 / 高脚凳转身 / 上下车露腿 / 回头露背 |
| 室内 | 睡衣伸懒腰 / 镜前更衣拉肩带 / 浴袍系带 / 湿发擦身 / 床上翻身 |
| 办公室 | 弯腰拿文件 / 跨坐桌沿 / 脱西装外套 / 解衬衫第一颗扣 |
| 夜店 | 贴身舞 / 低胸背影 / 被拉出人群 / 举杯仰头 |
| 车内 | 湿透衬衫贴身 / 跨坐副驾 / 后座压倒 |
| 床上 | 被子下相拥 / 只裹床单坐起 / 背部裸露 / 压上翻身 |
| 胁迫 | 被按墙 / 衣领被撕开 / 绑在椅上 / 被扛在肩上 |

## 五、开场 3 秒

- **每集首镜、每场首镜** — 主角登场第一镜 = 性感视角 + 动作 + 态度。不用空镜开场，除非跨时空非用不可
- **性感镜头必须带动作** — 弯腰、跨坐、拉丝袜、解扣、脱外套、擦身、翻身、转身、上下车；静止摆拍不算
- **男主同样** — 解领带、脱衬衫、湿身、单手撑墙、扛人

| 场景 | 首镜示例 |
|---|---|
| 酒吧初遇 | 苏曼跨下高脚凳，裙摆滑过大腿，端着酒杯朝镜头方向走来 |
| 深夜办公室 | 程曦弯腰从底层抽屉取文件，衬衫领口敞着，抬眼看向门口 |
| 清晨公寓 | 林漾只披着男式衬衫走到窗边拉开窗帘，衬衫下摆刚过大腿 |
| 胁迫 | 刀疤强一脚踢上门，周晓雨退到墙角，手背在身后摸门把 |

## 六、运镜

- **运镜字段只写**：固定 / 缓推 / 缓拉 / 跟随 / 环绕 / 摇 / 手持 / 焦点转移。不写升格、慢动作、迷幻、失焦、漂浮（这些是后期）
- **运镜跟着动作走** — 缓推只配动作（她边解扣边走来）；环绕只配动作（拥吻中退向床）；不能用运镜「让镜头慢下来」
- **一镜到底** — 只用于连续位移（长廊 → 刷卡 → 进门 → 被压到门上），8–12s，每集最多一处
- **焦点转移** — 前景婚戒 / 酒杯 / 手机 → 后景人物，标注「焦点转移：前景 X → 后景 Y」，本身就是一次信息推进，不算静止镜头

---

## 七、时长

| 镜头类型 | 时长 | 说明 |
|---|---|---|
| 动作镜 | 2–4s | 一个动作完成即切 |
| 台词镜 | 按 4 字 / 秒 | 长台词按语义拆镜 |
| 性感登场 | 3–4s | 一镜全身 + 动作 |
| 吻 / 推倒 | 3–5s | 含推倒、抵墙动作 |
| 特写 | ≤ 3s | 必须带局部动作 |
| 空镜 | 2s | 只在跨时空用 |
| 一镜到底 | 8–12s | 每集最多一处 |

- **3 秒规则** — 3 秒内没有新动作或新信息就切镜。没有「黄金 6 秒」，没有「停顿本身就是戏」
- **单镜不超过 5s**（一镜到底除外）

## 八、亲密与冲突动作（直接写）

- **拥吻拆两镜** — ① 中近景双人：吻落下，手进衣服下摆或揪住领口 ② 双人：推倒、抵墙、抱起，镜头跟随。不再「起势 / 局部 / 收势」三段
- **床戏拆三镜** — ① 脱外层：解扣、拉肩带、衬衫滑落 ② 双人翻身压上，床单、手臂、长发遮挡 ③ 底线转场：灯灭 / 被子拉起 / 关门。时长合计 ≤ 12s
- **胁迫拆三镜** — ① 压迫：抓腕、按墙、贴脸威胁 ② 挣扎：踢打、撕扯、衣领被撕开 ③ 结果：得逞被打断 / 救援踹门。每镜 2–3s，节奏快
- **救援** — 踹门 → 拉开或击倒 → 护在身后 / 抱住检查伤口。允许殴打反派、流血、撕破衣物
- **单镜动作不超过两个** — 「揪领带 + 吻上去」可以；「抬眼 + 起身 + 走近 + 吻」拆镜

### 允许直接写的动作

| 类别 | 动作 |
|---|---|
| 视线 | 对视、扫过身体、镜中对望、隔人群相望 |
| 靠近 | 贴耳、额头相抵、跨坐、压到墙上、抵在车门 |
| 触碰 | 抚脸、拨发、手贴腰、搂腰拉近、手探进衬衫下摆、掀裙摆、隔衣抚胸、揉腰、手搭大腿、解对方的扣子、解皮带、拉肩带 |
| 脱衣 | 脱外套、褪下衬衫、拉开裙侧拉链、拉丝袜、只剩内衣、浴袍滑落、只裹床单 |
| 吻 | 轻吻、吻颈侧、吻锁骨、深吻、抵墙之吻、车内之吻、床上之吻 |
| 拥抱与倒下 | 从背后环抱、抱起、推倒在沙发或床上、翻身压上、被子下相拥 |
| 事后 | 只披衬衫、床单滑落露背、吻痕、口红印、凌乱的床 |
| 胁迫 | 抓腕、按墙、捂嘴、撕衣领、绑缚、下药、扛走、贴脸威胁 |
| 救援 | 踹门、拽到身后、击倒反派、检查伤口、抱住安抚 |

### 三条底线（唯一的禁止项）

1. 未成年角色不参与任何上述亲密或性感镜头
2. 血亲之间不写亲密动作
3. 不直接画出生殖器、女性乳头与性交动作本身；到这一步写遮挡（被子、床单、手臂、长发）或底线转场

---

## 九、台词

- 亲密段落台词标注「低声」「气声」「贴耳」，句子短，不超过 12 字
- 潜台词优先 —「你不该来的」比「我想要你」更撩人
- 一句台词对应一个镜头，切换说话者时切镜头
- 沉默不写成镜头；吻前的静默由剪辑做
- 内心独白配动作镜（解扣、擦身、看手机），不配嘴不动的近景

---

## 十、转场

- **默认硬切**，同场内一律硬切
- **底线转场只在触到第三条底线时用** — 灯灭、被子拉起、关门落幅在门缝光线、纱帘落下；1–2s，每集最多两次。不是每场亲密戏都要转场，拥吻、推倒、脱外层直接拍完
- **跨时空** — 一个 2s 空镜或直接叠化（叠化由剪辑做，分镜表只标「切下一场」）
- **不写迷幻转场**（光斑过曝、失焦再对焦是后期）

---

## 十一、写完自检

- 每镜都有可见动作？没有「停顿 / 静止 / 缓慢 / 升格 / 凝视 / 呼吸交错」？
- 相邻两镜三要素至少换了两项？同一人物同一景别没有连续两镜？
- 每场「对视」≤ 1，「手部特写」「唇部特写」各 ≤ 1，空镜 ≤ 1？
- 每集首镜、每场首镜是性感视角 + 动作？
- 特写 ≤ 3s 且带动作？没有唇、眼大特写？
- 单镜 ≤ 5s？一镜到底 ≤ 1 处？
- 每镜能说出推进了什么？说不出的删了吗？
- 正反打没有超过两轮？
- 只有三条底线，其余亲密、脱衣、胁迫、救援都直接写了？
