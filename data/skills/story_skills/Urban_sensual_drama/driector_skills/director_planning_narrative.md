# 叙事手法 · 都市情欲 · 技法参考

> 导演规划的产出只有三样：分场汇总表、逐场注意事项、场间过渡。它不出镜头、不写配乐与光影。本手册定义的是：怎么给每场打情绪浓度、注意事项里必须写什么、怎样在规划阶段就把拖沓和重复砍掉。

---

## 一、主题立意与情感内核

- **先给，再拉** — 观众前 3 秒就要看到「这个人为什么让人想看」：身体、姿态、眼神一起上。性感不靠人设慢慢铺，先用画面抓住人，再用禁忌和代价留住人
- **性感 = 身体 + 姿态 + 态度** — 露肤、曲线、撩人动作是第一层，慵懒、自信、危险感是第二层，两层同框才成立。不要用「性感来自人物而非暴露」这种说法回避身体
- **禁忌必须有代价** — 婚外情、前任、上下级、好友的伴侣、无血缘继亲的吸引力来自代价：名誉、婚姻、事业、友情。只写甜不写代价，张力会塌
- **权力与吸引交织** — 身份差、信息差、主动权来回易手；谁先失控，谁就输一局
- **离场感受** — 心跳加速 / 上头 / 意难平 / 欲罢不能

### 内容底线（只有三条，其余全部允许）

1. 未成年角色不性感化；情欲相关角色一律成年
2. 血亲关系不情欲化；伦理关系限于无血缘的成年人
3. 不直接画出生殖器、女性乳头与性交动作本身；到这一步用被子、床单、手臂、长发遮挡，或剪影、灯灭、关门转场

以下内容都允许并且要直接拍出来：内衣、睡衣、浴袍、湿身、更衣、沐浴、脱衣过程、拉肩带、解扣、掀裙摆、隔衣或遮挡下的抚摸胸腰臀、跨坐、推倒、床上翻身压上、事后的衬衫与床单、吻痕、口红印；胁迫、按墙、捂嘴、撕衣、绑缚、下药、扛走作为剧情直接呈现；英雄救美、踹门、护在身后、殴打反派；夜店、微醺、迷幻段落。

## 二、节奏：每场必须推进

- **欲望阶梯可以跳级** — 八级仍是坐标（对视 → 试探 → 越界触碰 → 差一点的吻 → 失控之吻 → 拥吻推倒 → 床戏与遮挡转场 → 余温与代价），但不再要求逐级走：
  - 每集开场 30 秒内至少到第 3 级，或给一个性感视角登场
  - 每集至少一次第 5 级以上
  - 同一对人物在同一级停留不超过两场
- **「差一点」只能用一次** — 同一对人物的「差一点的吻」全剧最多一次，之后直接吻、直接推倒。反复「差一点」是拖沓的头号来源
- **推拉每轮升级** — 靠近 → 退缩 → 更近 → 失控 → 代价。退缩不超过一场；每轮都比上轮更越界、更危险
- **每场回答一句话** — 本场推进了什么：关系升级 / 秘密线推进 / 危险升级，三选一。答不出来的场合并进相邻场，或在注意事项里标「本场无独立推进，压缩到 1–2 镜」
- **余温只留一镜** — 高张力段落之后的独处、清晨、回味最多一镜，不单独成场
- **秘密线并行** — 隐瞒 → 蛛丝马迹（口红印、吻痕、未接来电、酒店房卡）→ 险些暴露 → 当场撞破 → 对峙。情欲越浓，暴露越近
- **转折用身体不用台词** — 摘下的婚戒、没有推开的手、被拉开的拉链、关上的门

## 三、分场情绪设计（导演规划实际要写的）

### 情绪浓度口径

| 浓度 | 场次性质 | 规划处理 |
|---|---|---|
| 0–3 | 过场、信息交代、纯氛围 | 标「压缩」，最多 1–2 镜，能并入相邻场就并入 |
| 4–6 | 试探、暧昧、秘密线铺垫 | 正常拆，但必须带一个性感视角 |
| 7–8 | 越界触碰、失控之吻、胁迫、撞破、救援 | 本集砸点，注意事项写清动作 |
| 9–10 | 拥吻推倒、床戏、摊牌决裂 | 全集高潮，允许一镜到底 |

### 逐场注意事项必写四项

1. **开场钩子** — 本场首镜给谁的什么性感视角或动作（例：「苏曼背对镜头拉上裙侧拉链，回头」）。空镜不能当开场钩子
2. **推进项** — 本场推进了关系级别 / 秘密线 / 危险中的哪一项
3. **空间距离** — 两人从多远到多近，用什么把距离压缩（电梯、车内、被按到墙上）
4. **忌拖沓项** — 本场不许出现的东西：多余空镜、第二次对视、无动作的特写、重复的正反打

### 典型段落

| 段落类型 | 情绪方向 | 直接给的画面 | 开场钩子示例 |
|---|---|---|---|
| 初遇电流 | 惊艳 + 危险 | 一镜给全身与姿态，视线相撞后立刻有动作（走近、递酒、擦肩） | 她跨下高脚凳，裙摆滑过大腿 |
| 暗室试探 | 紧张 + 渴望 | 电梯、衣帽间、车内，身体贴上，手先动 | 他替她拉外套拉链，手停在腰侧 |
| 越界之吻 | 失控 + 罪恶感 | 直接吻，抵墙或车门，手进衣服下摆 | 她一把揪住他的领带 |
| 夜店迷幻 | 迷离 + 放纵 | 贴身舞，霓虹下的腰与背，人群中被拉走 | 她在舞池里转身，背部全露 |
| 雨夜车内 | 私密 + 挣扎 | 湿透的衬衫贴身，车窗起雾，跨坐到他腿上 | 她湿着头发钻进副驾 |

| 英雄救美 | 爆发 + 保护 | 踹门、拉开、护在身后，事后的检查伤口与拥抱 | 门被撞开，他一把把她拽到身后 |

### 距离叙事

- 初期隔着人群、桌子、玻璃；中期被迫贴身（电梯、车内、舞池）；后期零距离
- 零距离不等于大特写：拥吻、床戏用中近景双人拍，身体关系看得清
- 镜子 = 另一个自己；门缝 = 窥视与秘密；落地窗 = 欲望暴露在城市面前；电梯 = 倒计时；婚戒 = 代价

## 四、性感视角：前 3 秒抓人

- **每场至少一个性感视角镜头，放在前两镜** — 主角登场第一镜就是身体 + 姿态 + 态度，不用「鞋 → 腿 → 腰 → 回眸」四段揭示，一镜中景全身直接给
- **性感镜头必须带动作** — 弯腰、跨坐、拉丝袜、解扣、脱外套、擦身、翻身、伸懒腰、转身、上下车，不能是静止摆拍
- **男主同样要** — 解领带、脱衬衫、湿身、擦汗、单手撑墙、扛人
- **配角与反派也可用** — 反派的危险感靠贴脸、抓腕、居高临下；女配的性感靠对比（更艳、更冷、更主动）

| 场景 | 可直接用的性感视角 |
|---|---|
| 登场 | 中景全身走来、高脚凳转身、上下车露腿、回头露背 |
| 室内 / 家 | 睡衣伸懒腰、镜前更衣、浴袍系带、湿发擦身、床上翻身 |
| 办公室 | 弯腰拿文件的领口、跨坐桌沿、脱西装外套、解衬衫第一颗扣 |
| 夜店 / 派对 | 贴身舞、低胸背影、被拉出人群、举杯仰头 |
| 车内 / 雨夜 | 湿透衬衫贴身、跨坐副驾、后座压倒 |
| 床上 | 被子下相拥、只裹床单坐起、背部裸露、压上翻身 |
| 胁迫 | 被按墙、衣领被撕开、绑在椅上、被扛在肩上 |

允许的机位：俯拍领口、低角度腿部、背部曲线、侧腰、跨坐正面、镜前、床上俯拍双人。没有「低俗机位」禁令，只守三条底线。

## 五、声音方向

- 分镜表只写环境音与音效；配乐、吻前静默、音乐骤起交给剪辑，规划里不写
- 亲密段落的细节音：呼吸、丝缎摩擦、拉链、皮带扣、领带抽出、高跟鞋落地、冰块碰杯、床架轻响
- 胁迫与救援的细节音：门被踹开、布料撕裂、椅子倒地、急促呼吸、耳光

## 六、拖沓与重复自检（规划阶段就要剔除）

- 相邻两场同一空间、同一情绪、没有新推进 → 合并
- 一集内「对视」类砸点不超过两次；第二次必须伴随触碰
- 纯氛围场、纯回味场删掉，改成一镜并入相邻场
- 每集开场定场空镜最多一个，并且首镜优先给人不给景
- 「差一点的吻」全剧最多一次
- 任何场次注意事项里没有开场钩子 → 补；没有推进项 → 压缩
