## 题材附加规则 · 古风情欲

> 仅当【项目配置】包含「题材规则：古风情欲（启用）」时执行本章节。

### 改编原则追加

- **提前给性感**：原著慢热的，改编时把第一处身体 / 姿态 / 撩人动作提前到第一集前 30 秒；原著一笔带过的隔帘对视、递物、执手、梳妆、沐浴、更衣、侍寝，扩写为完整段落
- **压缩无关支线**：与欲望主线、身份禁忌线、危险线无关的朝堂 / 宅斗 / 江湖支线优先删减；两场戏没有新推进就合并
- **禁忌必须保留代价**：性命、名节、家族、江山的后果不得删除
- **空间选择**：关键对手戏改到私密或封闭空间（闺阁、浴池、马车、舟中、军帐、密室、青楼厢房、囚牢）
- **武侠与战争为情欲线服务**：决斗、刺杀、战场、刑讯要落到身体上（包扎、血衣、鞭痕、湿衣），并紧接一次身体接触；原著没有的强抢、掳人、逼婚、下药、英雄救美，只要服务欲望线或危险线，可以增补
- **古风词汇**：肚兜、亵衣、罗帐、锦被、合卺、盖头、落红、点穴、镣铐直接用，不用现代词替代

### 情绪基调

- 基调锁定为：媚、狠、悲、上头；避免纯甜宅斗或纯热血武侠
- 情欲戏的「甜」必须伴随「危」——门外的脚步、案上的剑、明日的圣旨

### 底线（改编时强制修正原著）

- 原著中未成年角色的情感线：改编为成年，或删除亲密内容；丫鬟、书童、歌姬默认成年
- 原著中血亲间的情欲内容：删除或改为无血缘（姻亲、义结、师徒）
- 原著中直接描写生殖器、乳头、性交动作的段落：保留到宽衣、翻身压上为止，在底线处写遮挡或烛灭转场
- 原著中的强抢、胁迫、下药、刑讯情节**原样保留**，不必改成双方意愿，也不必强行加惩罚
