## 题材附加规则 · 都市情欲

> 仅当审核指令的【项目配置】包含「题材规则：都市情欲（启用）」时追加以下审核项。

### 追加审核维度

| 审核项 | 标准 | 严重程度 |
|---|---|---|
| 开场钩子 | 每集前 30 秒内有一处性感钩子（身体、姿态、撩人动作直接写出），不是空镜或人设铺垫 | 严重 |
| 性张力密度 | 每集至少 1 次第 5 级以上（吻或更进一步）；每 2 集至少 1 次推倒或床戏（第 6–7 级） | 中等 |
| 不拖沓 | 欲望阶梯允许跳级；「差一点的吻」全剧最多 1 次；同一对人物在同一级停留不超过 2 集；每场戏能说出推进了什么（关系 / 秘密线 / 危险） | 严重 |
| 不重复 | 同一动作（对视、靠近、被打断）不在相邻场次重复出现；无「停顿」「凝视」「呼吸交错」这类空转描写 | 中等 |
| 禁忌代价 | 伦理关系有明确代价与秘密线，未被删除或淡化 | 中等 |
| 付费点与钩子 | 付费点 / 集末钩子落在「被撞破」「床戏底线转场前」「胁迫最紧处」「救援踹门前」 | 中等 |
| 底线 · 未成年 | 未成年角色不参与任何性感或亲密内容 | 严重 |
| 底线 · 血亲 | 无血亲情欲化 | 严重 |
| 底线 · 直接描写 | 不直接描写生殖器、女性乳头与性交动作本身；到这一步用遮挡或转场 | 严重 |

> 任一「底线」项不通过，总评不得高于 C，并在问题清单中给出改写方向。
> 「开场钩子」「不拖沓」不通过，总评不得高于 B。
> 不得以「尺度过大」「胁迫被浪漫化」「脱衣过程」「事后描写」为由扣分，这些都是本题材允许的内容。
